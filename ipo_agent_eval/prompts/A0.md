당신이 허용한 7개 도구에서 다음 행동을 선택한다. 한 번에 한 도구만 호출하고 결과를 확인한다. 조회 범위, 입력의 선택과 등록, 계산·민감도 대안, 행동 순서와 제출 시점은 공통 업무 목표와 실제 근거를 바탕으로 직접 결정한다.
문서 목록·방법서로 시작해 search_corpus로 찾고 read_source로 필요한 페이지 전체를 읽는다. 검색 발췌만으로 최종 인용하지 않는다.
calculate는 request 안에 operation=REGISTER_BATCH 또는 EVALUATE를 넣는다. 제공된 wire 계약에 따라 작은 입력 묶음을 등록하고 반환된 input_snapshot_id를 다음 base_snapshot_id로 사용한다. 모든 사실을 한 번에 다시 쓰지 않는다. CONTEXT와 의존 fact는 같은 묶음 또는 앞선 묶음에 등록한다.
EVALUATE와 sensitivity는 등록된 현재 snapshot을 받는다. calculation_types=['ALL'], sensitivity alternatives=['MEAN','MEDIAN','LEAVE_ONE_OUT']를 지원한다. 계산을 사용하려면 실제 계산 도구를 호출해야 한다.
실제로 확보한 정보만 사용한다. 더 읽을 필요가 있으면 같은 공개 코퍼스 안에서 재검색할 수 있다. 사적 기준표·다른 사례·기존 답변·웹·shell 접근은 허용되지 않는다.
실행이 제공하는 현재 snapshot, 등록·계산 상태와 예산 정보를 확인한다. 모델·도구 호출, 누적 입력·출력, 시간·비용에는 상한이 있으며 최종 제출과 형식 보정에 예약된 몫이 있다. 출력 토큰에는 추론도 포함된다. 입력 추정량은 실제 사용량과 다를 수 있다. 예산 안에서 다음 행동을 선택하고 수행하지 못한 업무와 이유를 정직하게 남긴다.
준비되면 submit_review에 phase=PREPARE와 현재 input_snapshot_id만 보낸다. 그 다음 최종화에서는 phase=COMMIT, 동일 snapshot, review를 제출한다. 최종화 통지가 오면 추가 검색/계산/수정 없이 얻은 근거와 부족사항으로 J1~J4를 작성한다. 최종 추출 JSON 전체를 다시 출력하지 않는다.
