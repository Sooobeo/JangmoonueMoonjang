# 다중 기업 파일럿의 입력 목표 조정

2026-11-13, 새 기업의 실제 모델 답변을 받기 전에 B 설정을 `0.2.1-pilot`로 정했다. 담당은 규리이며 Codex가 공개 입력의 크기를 점검하고 설정을 조정했다.

멜콘은 고정된 다섯 검색과 앞뒤 쪽 열람으로 36쪽을 선택했다. 공통 지시를 합친 공개 입력은 `o200k_base` 기준 약 48,956토큰이다. 추출·검토에서 원문을 각각 보내고 추출 결과, 계산 결과, 형식수정 예약분을 더한 계획 추정은 약 137,920토큰이었다. 기존 120,000 목표에서는 검토 호출 전에 중단될 가능성이 있어 새 파일럿의 공통 입력 목표를 160,000으로 변경했다. 실제 토큰 수와 차이는 실행별 사용량에 기록한다.

[프로토콜](../../whole%20plan/IPO_Experiment_Protocol.html)의 자원 예산 규칙은 초기 수치를 파일럿에서 조정할 제안값으로 두고 최종 평가 전에 고정하도록 한다. 이번 조정은 모델 답변이나 채점 점수를 보고 한 변경이 아니다. 정답에 맞춘 검색어·선택 쪽 추가도 하지 않았다.

모델 `gpt-6.1-terra`, 추론 `medium`, 고정 다섯 검색, 상위 3쪽과 인접 1쪽, 호출 16회, 도구 40회, 출력 16,000토큰, 600초, 실행당 0.30달러는 유지했다. 입력 160,000을 전부 30분 캐시 쓰기로, 출력 16,000을 일반 출력으로 계산하면 0.28달러다. [공식 Terra 요금](https://developers.openai.com/api/docs/models/gpt-6.1-terra)을 2026-11-13 재확인했다. 청구서 금액은 아니며 장기 전체 평가 예산은 파일럿의 실제 사용량을 반영해 다시 산정해야 한다.

`0.2.0-pilot`에서는 등록 사례 선택, 사례별 제목과 해시 기록, 검색어의 HDMS 전용 연도 삭제, 공통 방법서 분리를 적용했다. HDMS 원본 입력과 기존 `0.1.4-pilot` 답변은 그대로 보존한다. 기존 HDMS 점수와 새 사례의 점수는 개발 현황으로 함께 볼 수 있으나, 동일 설정에서 얻은 통제 비교 결과로 해석하지 않는다. 최종 조건 비교에서는 같은 고정 설정을 모든 조건에 적용해야 한다.
