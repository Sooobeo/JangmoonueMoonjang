# v0.4.2 명시 분모 선택 우선순위 1차 검토

PASS. DTS B에서 공시 분모와 파생 분모 선택이 공존해 주당 계산이 불가했다. 코드 대조 결과 share_count를 명시해도 모든 alias 선택과 함께 세어 모호하다고 처리하는 우선순위 결함을 확인했다.

이제 정확한 역할·회사에 대한 명시 선택을 먼저 존중한다. 명시 UNRESOLVED는 다른 usable alias로 대체하지 않고, 명시 역할 선택이 없을 때만 기존 alias 유일성/단일 fact 대체 규칙을 쓴다. 모델 대신 분모를 만들거나 고르지 않는다. 공통 prompt에 같은 계약을 설명했다.

새 4개 회귀는 공시/파생 중 각각의 명시 선택, 명시 미해결 유지, 미선택 모호함 유지와 snapshot 원본 보존·민감도 연결을 검증한다. 기존 계약·계산·wire·patch·통합을 포함해 114개 통과(5.26초). 최초 새 fixture의 미선언 근거 ID 오류는 fixture만 수정했다.
