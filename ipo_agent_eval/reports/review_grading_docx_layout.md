# 채점용 Word 문서 확인 기록

확인일은 2026년 11월 12일이다.

첫 번째 점검에서는 실제 질문과 답변, 기존 채점기준을 대조했다. 모델이 작성한 문장 42개와 추출값 21개, 계산값 40개, 출처 38개를 보존했으며 점수는 비워 두었다. 모델에게 전달한 공시 30쪽을 부록으로 넣었다.

두 번째 점검에서는 F1부터 F5, K1부터 K3, J1부터 J4의 기준과 기록란을 확인했다. 원래 기준표의 절 번호를 이 문서에 맞게 바꾸고, 모델 입력에 없었던 참고 자료는 평가자용이라는 맥락을 남겼다. 메모 목록, 숫자의 줄바꿈, 표의 열 너비도 고쳤다. 두 자리 표시값을 추가하면서 계산상 원값은 모두 유지했다.

세 번째 점검에서는 렌더 v3의 65쪽 전체를 원본 해상도로 열어 확인했다. 1~20쪽, 21~40쪽, 41~65쪽을 나누어 보았다. 최종 렌더 v4에서는 바뀐 14쪽을 다시 원본 해상도로 확인했고, 나머지 51쪽은 PNG 바이트가 이전에 확인한 이미지와 완전히 같음을 대조했다.

최종 문서는 65쪽이다. 36~65쪽에 공시 이미지가 한 장씩 있으며 사이에 불필요한 빈 페이지가 없다. 표가 이어질 때 머리행이 반복되고, 셀과 문단의 잘림이나 겹침은 확인되지 않았다. 머리말은 PDF 좌표와 PNG 상단을 별도로 대조해 모든 쪽에서 정상임을 확인했다. 긴 원값과 비교하기 쉬운 짧은 표시값은 별도의 표로 구분했다.

관리형 문서 도구로 DOCX를 작성했다. Windows 런타임에 번들 LibreOffice가 없어 Word COM의 PDF 내보내기를 작업 폴더의 변환 함수로 사용하고, 공식 render_docx.py의 PNG 생성 과정을 실행했다. 관리형 도구 원본은 수정하지 않았다.

최종 파일 SHA256은 `24d5e1967f4de50173f74c9c196532f786a7a09fb6b5669829356b333a3d07c6`이다. ZIP 무결성 확인을 통과했으며 표 17개와 공시 이미지 30개가 들어 있다. 모델 답변의 점수, 개발 비용, 실제 실행 방식 식별자는 문서에 넣지 않았다.
