설계서 D0~D6의 구현, 개발기업 6곳의 B/A0 실제 비교, 채점과 A1 인계표를 작성하고 **각 단계 세 차례 검토와 전체 완료 후 세 차례 종합 검토를 마쳤다.** 실제 실험의 실패와 계산 미수행은 그대로 보존했다.

## 구현과 검증

기존 v1과 원본 자료를 보존하고 v2를 분리했다. 새 계약은 직접값·파생값·미확인·0을 구별하며, 주식수 포함/제외·단위·시점·기업·원문 근거를 불변 snapshot에 연결한다. 계산기는 선언된 입력을 Decimal로 계산하고 직접값과 파생값의 차이를 남긴다.

B와 A0는 같은7개 도구, 공개 코퍼스, v2 계약과 예산을 사용한다. B는8개 고정 검색을 수행하고 A0는 다음 도구를 선택한다. 원문은 페이지 전체를 반환한다. PREPARE/COMMIT, 공유 형식수정1회, 최종 입력·출력·시간·도구 예약, 실제 call_id·actor·원시 usage·실패를 기록한다.

전체 회귀는 **284 passed in 16.17s**다. [T01~T20 테스트 연결표](requirements_test_mapping.json)는 주식수·파생 계산·정정 기준·근거 전파·격리·예약·API 실패·상태·새 실행·계산 사용/배제·의미 오류 비수정 경로를 연결한다. 실제 API 도구 스키마 확인과 실패 요청 재전송 호환성 확인도 별도로 수행했다.

[보존 검사](final_preservation_check.json)는702개 기준 항목을 확인해 위반0건이다. 수정하면 안 되는 증거667개와 원래 소스/설계 사본35개를 보존했다. 사용자 기존 작업은 되돌리지 않았다. 기존 R001 점수를 새 실행 점수로 재사용하지 않았다.

W09는 개발6기업의 전체 공개 입력·분리된 기준표와 평가 후보12기업의 출처·적격성·배정 기록까지 준비했다. 후보12개는 아직 최종 평가 코퍼스/기준표가 완성된 상태가 아니며 답변을 요청하지 않았다. [사례 모집·배정 기록](case_roster.md)

## 버전과 모든 시도 보존

최초 무료 점검에서 멜콘의 상위3쪽 검색 계획은 입력 예약 상한을 넘었다. 실제 답변을 받기 전에 모든 기업·조건의 공통 검색 상한을2로 조정한0.3.1을 만들었다. 여덟 검색과 전체 쪽 열람, 모델·토큰·금액·시간 상한은 유지했다.

0.3.1의 A0는 SDK 출력 항목을 그대로 재전송하는 과정에서 HTTP400을 겪었다. 최종 실패3회와 진행 중이던1회, 미착수8개를 보존하고 배치를 중단했다. 전송용 사본만 정규화하는0.3.2를 별도로 동결해 B/A0 각6회를 모두 다시 실행했다. 원시 응답·reasoning·call_id·본문은 보존했다. 새12회에서 유리한 답변만 선택하거나 답변을 다시 고쳐 채택하지 않았다.

## 비용

실제 cached/write/ordinary usage로 계산한 이번12회의 알려진 비용 추정은 **$0.80509405**다. 서버 오류 요청1회의 사용량이 없어 총액은null이다. 이전 실패·중단4회와 호환성 진단2회까지 포함한 전체18개 시작 시도의 알려진 비용 추정은 **$1.09106735**, 사용량 불명 요청은3개다. 청구서를 확인한 값은 아니다. [전체 비용 기록](all_attempt_costs.json)

별도 감사의 표준 비캐시 요율 추정은 이번$1.305799, 전체$1.688541이다. 이는 입력 캐시 쓰기1.25배를 반영한 실행기의 예산 상한 검사와 다른 계산이다. 캐시 쓰기 때문에 개별 실행의 캐시 반영 비용이 표준 비캐시 추정보다 클 수도 있다. 어느 추정도 실제 청구액으로 부르지 않는다. 불명 사용량을0원으로 합산하지 않았다.

## 후속 인계

[A1 인계표](D6_failure_handoff.md)는25개 실패·누락 기록을 실제 실행에 연결한다. 같은 실행의 여러 문제를 구분한 기록 수이며 실패 실행은10회다. 후보는 탐색 중 등록·계산 진행 확인, 미해결 의존성 선언 확인, 코퍼스 내부 작업과 외부 요청 구분의3개다. 추가 호출·비용은 아직 측정하지 않은 계획 가정이다.

B의 추출 계약·공백 반복과 공통 형식 수정의 실행 가능성은 공통 보완으로 분리한다. A1은 구현하지 않았고 효과도 주장하지 않는다. 다음 작업은 이 관찰에 근거한 W11 설계이며 최종 평가 동결은 W12 이후다.
