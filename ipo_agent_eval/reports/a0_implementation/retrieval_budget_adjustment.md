# 실제 답변 전 공통 검색 한도 조정

2026년 11월 13일 한국시간. 상세설계 7.2·14절이 허용한 무료 사전 점검에 따른 개발 설정 조정이다.

0.3.0-dev의 검색 8개 × 상위 3개 × 앞뒤 한 쪽 정책에서 멜콘은 중복 제거 후 54쪽이었다. 추출 요청 추정 79,426 + 최종 요청 기본 78,496 + 추출·계산 확장 여유 15,000 + 형식수정 입력 16,000 = 188,922토큰으로 160,000 상한을 초과했다. 실제 API를 부르지 않고 PREFLIGHT_BLOCKED_BUDGET로 보존했다. 상세 기록은 D3_preflights_initial.json과 해당 실행 폴더에 있다.

모든 v2 실제 답변을 받기 전에 0.3.1-dev로 조정했다. 모든 기업의 B 고정 검색 top_k와 B/A0 공통 검색 도구의 top_k 상한을 3에서 2로 낮췄다. 검색 문구 8개와 순서, 전체 페이지 및 앞뒤 한 쪽 열람, 같은 모델·추론·토큰·0.30달러·시간 상한은 유지한다. 모델별 또는 기업별 정답 페이지를 선택하지 않았다.

공통 검색 API는 top_k 1~2를 허용한다. 이미 아는 chunk ID를 읽는 공통 도구는 최대 3개·이웃 0~1쪽·최대 9쪽 계약을 유지한다. A0는 이 동일한 공통 접근 범위에서 다음 행동을 정한다.

실제 답변을 보기 전 새 한도로 다시 무료 점검한다. 사전 추정은 실제 토큰 수 보증이 아니며, 매 호출 직전 실제 요청 크기와 원본 usage 누적값으로 다시 차단한다.
