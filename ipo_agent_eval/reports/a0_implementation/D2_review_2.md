검토자: Codex preservation_review  
대상: `calculations_v2.py`, 기존 Decimal 계산·민감도 모듈, `tests/test_calculations_v2.py`

판정: **통과**. 이 단계에서 추가 수정이 필요한 결함은 발견하지 않았다.

직접 확인한 사항:

- INCLUDE 구성만 합산하며, 옵션은 모델의 명시적 포함/제외에 따라 달라진다. 미확인 EXCLUDE 구주는 완전 분모를 막지 않는다.
- 미완성 coverage·UNRESOLVED 구성·필요 수량 누락은 완전 합계 대신 부분합과 UNAVAILABLE로 남는다.
- 멜콘 합성 입력은 12,735,000주, DTS 합성 입력은 14,881,735주를 반환한다.
- 기준주가 20,000원과 5,000,000주에서 100,000백만원을 파생하고, 이익 10,000백만원에 대해 PER 10배를 계산한다. 원입력 P/S/E의 근거가 끝까지 유지된다.
- 직접 시가총액과 파생값이 다르면 두 값과 차이를 보존하며, 선택이 없으면 PER을 임의 확정하지 않는다.
- 계산 ID는 입력 스냅샷에 연결되며, 새 입력 등록 이후에도 과거 스냅샷의 결과를 재현할 수 있다.
- 누락된 비교기업을 자동 제외하지 않고 평균·민감도 실패를 보존한다. 허용한 대안만 반환하며 대안임을 표시한다.
- 40자리 Decimal 국소 컨텍스트를 사용해 외부 Decimal 정밀도 변경이 결과를 바꾸지 않는다.
