B의 6회는 모두 추출 응답 5,000토큰 상한에서 incomplete가 됐다. A0의 신성에스티·에이엘티·밀리의서재 3회는 최종 형식 수리 응답 2,500토큰 상한에서 incomplete가 됐다. HDMS A0는 형식 수리 호출에서 HTTP 500/server_error가 발생했고 미수신 사용량은 unknown으로 남겼다. `insufficient_quota`는 이 12개 실행 로그에서 발견되지 않았다. 계정 잔액 자체를 조회한 결과는 아니다.

제출된 MELCON A0와 DTS A0의 최종 상태는 모두 HUMAN_REVIEW다. 12회 모두 등록 snapshot은 초기 상태 1개이며 계산 결과는 0개다. 따라서 SUBMITTED 2회를 독립 산술 재현 성공이나 검토 완료로 해석해서는 안 된다. 두 제출의 인용 위치 48개는 실제 읽은 원문 페이지와 doc_id·chunk_id·물리 page가 일치했다. 계산 누락, blocking 정보 요청과 사람 판단의 적정성은 별도 잠정 채점에서 평가해야 한다.

감사에서 다음을 원시 파일과 대조했다.

- 각 요청의 모델·추론 수준·store=false·parallel_tool_calls=false와 동결 조건 설정이 일치한다. 각 실행의 코드·config·prompt 해시가 동결본과 일치하고 신규 3개 gold와 회사 배정표 해시도 유지됐다.
- 저장된 원시 API usage의 합이 summary의 입력 988,179·출력 63,524토큰과 일치한다. 요약 비용은 사전 요율로 다시 계산했다. 응답이 없는 HDMS A0 시도는 알려진 비용 $0.138507과 불명 총비용을 구별한다.
- 실제 tool_call 이벤트 수와 envelope usage_delta 합이 summary 도구 수와 같다. B는 program_fixed, A0의 자율 선택은 model, 최종 동기화는 program_commit으로 구분된다. model actor의 call_id·이름·인자가 저장된 원시 function_call과 일치한다. 요청/상신 도구의 외부 발송은 0회다.
- source read는 허용 코퍼스의 완전한 페이지이며 묵시적 절단이 없다. 반환된 본문·문서·쪽이 원본과 같고 retrieval_history와 source_packet의 읽은 집합이 일치한다. 12회 각각의 고유 열람 페이지 합은 285쪽이다.
- 저장 snapshot에서 논리 extraction이 재현되고 계산 ID 중복이나 존재하지 않는 snapshot 참조가 없다. ledger의 previous/current 이력을 재생한 값이 최종 ledger와 같으며, 두 제출은 ledger 전체와 최종 상태 규칙을 충족한다. FAILED 실행에는 최종 review와 내용 상태가 없다.
- 기존 불변 자료 667개와 보존 소스·설계 35개, 총 702개가 보존 검사에 통과했다. 이전 0.3.1 중단 배치의 81개 산출물도 바뀌지 않았다. 이번 0.3.2의 283개 산출물은 최종 검토에서 재검사할 수 있게 해시를 고정했다.

0.3.1은 실패 3회·중단 1회·미실행 8회로 별도 보존되어 있다. 알려진 사용량 비용 $0.362993과 불명 2건을 새 결과로 대체하지 않았다. 연결 smoke $0.002406과 실제 전송 호환성 probe $0.017343도 연구 실행과 분리했다. 이번 작업에서 이 네 범주의 **알려진 사용량 비용 합은 $1.688541**이며, 불명 사용량 시도는 총 3건이므로 총액은 null이다. 모두 사전 비캐시 요율을 사용한 추정이며 청구서 확정액이 아니다.
