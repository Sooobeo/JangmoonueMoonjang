T01~T20 전체에 연결된 고유 테스트 함수 32개를 AST로 확인했다. 기록된 최종 회귀는 284개 통과(16.17초)이며, 실행 소스는 실제 비교 때 동결한 파일들과 동일하다. 이 종합 검토에서 같은 회귀를 불필요하게 다시 실행하지 않았다. D0~D6의 각 세 차례 기록과 현재 문서의 기존 산출물 링크도 확인했다. 아직 작성 중인 종합 후속 검토 링크는 완료 상태를 미리 주장하는 근거로 삼지 않았다.

사전 계획 12개 쌍의 결과와 원시 기록을 다시 검사했다. 모델 61회·도구 159회, 제출 2회·실패 10회이며 모든 사례가 분모에 남는다. 제출 2회는 HUMAN_REVIEW이고, 전 실행의 등록 snapshot은 초기 상태이며 계산 결과가 없다. 강제 미제출 항목의 0점은 원 프로토콜 §11.1과 일치하고, 미관찰 의미 오류·잘못된 완료·불필요 보류는 null로 남긴다. A0의 F 7/30·K 0/18·방법론 3/24는 합계/8 대신 J=2 개수로 계산된다. 사람 확정·블라인드 채점·사람 작업시간이 완료됐다고 표시하지 않는다.

원시 usage에서 입력을 ordinary/cached/cache-write로 독립 분해해 기록된 단가를 적용했다. 현재 12회의 캐시 반영 알려진 비용 $0.80509405와 이전 실패·중단·진단을 합한 18개 시작 시도의 $1.09106735가 보고서와 일치한다. 사용량 없는 호출 3개 때문에 전체 비용은 null이고 청구서 값은 없다. 표준 비캐시 요율의 별도 합계 $1.305799/$1.688541과 실행기의 cache-write 예산 상한은 다른 값으로 구분한다.

파생 보고서 생성기 세 개를 원본 읽기와 메모리 안의 출력 수집만으로 실행했다. 실행 비교 JSON, 채점 집계 JSON/Markdown, 전체 비용 JSON, D6 JSON/Markdown 등 **6개 출력의 전체 본문이 현재 파일과 일치**했다. 실제 파일은 다시 쓰지 않았다.
