# 기존 3기업 B/A0 개발 실행 보조 채점

대상은 동결된 D5_v032의 HDMS·MELCON·DTS 각 B/A0 1회, 총 6회다. 6회 모두 종료되어 채점을 마쳤다. 4회는 최종 제출 실패이고, MELCON A0와 DTS A0의 2회는 HUMAN_REVIEW로 제출됐다.

이 기록은 조건명을 확인한 AI 비블라인드 보조 채점이다. 사람의 독립 검토·최종 확정과 실제 사람 채점 시간 측정은 완료하지 않았다. 최종 평가 20기업이나 통계적 우월성 결과로 해석하지 않는다.

## 채점 정책

프로토콜 §11.1에 따라 실제 시도했으나 최종 review를 제출하지 못한 실행의 F1~F5·K1~K3·J1~J4는 모두 0점이다. 방법론적 충족률은 count(J=2)/4이며, 부분 추출이나 거부된 초안을 최종 답안으로 대체하지 않는다. 미실행 항목은 점수 null이다.

최종 답안이 없는 실행의 내용 오류·잘못된 완료·불필요한 보류는 미관찰(null)이다. 미제출의 0점과 확인된 내용 오답은 구분한다. 최종 상태도 null로 유지하며, 초안의 PENDING_INFO를 최종 상태로 바꾸지 않는다.

## 이전 실행 이력

D5_v031의 종료 실패 3회와 루트 에이전트가 공통 API 입력 결함을 확인한 뒤 중단한 1회는 보조 구현 이력으로만 보존한다. 중단 1회는 운영자에 의한 중단이며 모델 검토 품질 실패로 귀속하지 않는다. 주 비교에는 D5_v032만 사용한다. [이전 이력 독립 감사](D5_v031_interrupted_review_2.json)

이 보고서는 실제 청구서·사람 검토 결과·완료된 최종 평가를 대신하지 않는다. 비용과 usage의 전체 집계는 배치 비교 보고서와 연결한다.

## 출처 적합성과 근거 지지율

제출 review.json의 judgments[].facts[]에 구조화된 사실 주장만을 분모로 한다. 각 claim은 한 번 집계하고 여러 인용은 묶어서 확인한다. 사실 묶음 F1~F5의 완전성, 전체 결론·unknowns·memo·요청·계산의 정확도 또는 독립 외부 원천 검증을 측정하는 지표가 아니다.

실제 열람 여부는 성공한 read_source 호출의 doc/chunk/page와 source_packet의 원문 텍스트를 대조했다. 의미적 지지는 그 다음 원문 내용과 주장 전체를 대조해 FULL·QUALIFIED·UNSUPPORTED로 별도 판단했다. FULL만 엄격 지지율 분자에 넣고 QUALIFIED를 제외한다.

| 기업 | 조건 | 제출 사실 주장 | 열람 위치 유효 | FULL | QUALIFIED | UNSUPPORTED | 엄격 지지율 |
|---|---|---|---|---|---|---|---|
| HDMS-DEV-01 | B | 0 | 0 | 0 | 0 | 0 | null (미관찰) |
| HDMS-DEV-01 | A0 | 0 | 0 | 0 | 0 | 0 | null (미관찰) |

실패 4회의 계수 0은 관찰할 최종 주장이 0개라는 뜻이며, 지지가 0%라거나 오류가 없었다는 뜻이 아니다. 전체 제출 사실 주장 21개 중 FULL 20개, QUALIFIED 1개로 엄격 지지율은 20/21(95.24%)다. 이 비율은 누락된 필수 사실·계산이나 전체 결론의 정확도를 대체하지 않는다.
