# D5 0.3.1 중단 배치 독립 2차 검토

검토자: preservation_review. 2026-11-13 10:18:55 UTC 기준.

**기록·사용량·자료 격리·보존 검사는 통과했다. 개발 비교는 완료되지 않았다.** 12회 계획 중 최종 실패 기록 3회, 운영자 중단 1회, 미실행 8회를 구별했다. 원래 계획, 점진 결과, 실행 디렉터리를 수정하지 않았다. 판정 근거와 81개 실행·계획 산출물의 SHA256은 `D5_v031_interrupted_review_2.json`에 있다.

비용은 저장된 원시 응답의 입력·출력 토큰에 사전 설정된 비캐시 요율을 적용한 추정이다. 청구서 확정 금액이 아니다. HDMS A0의 실패 API 시도와 MELCON A0의 응답 미수신 시도를 0원으로 처리하지 않았다. 별도 연결 점검 $0.002406은 이 배치 합계에 포함하지 않았다. 중단과 미실행은 최종 성공·실패 판정의 대체값이 아니다.

MELCON A0는 모델 시도 10회 중 9회 응답을 보존했다. 확인 가능한 입력 134,089, 출력 4,283토큰이고 마지막 `10_format_repair_request.json`의 응답은 없다. 도구 11회는 모델이 선택한 9회와 최종 요청 동기화 프로그램 호출 2회로 나뉜다. 13개 고유 원문 페이지를 완전한 형태로 읽었고, 제출 시도에 담긴 인용 위치 24개가 그 실제 열람 집합에 속한다. 마지막 최종 제출은 `missing_inputs`와 선언된 UNRESOLVED 의존성 불일치로 거절되었다. 동기화된 OPEN 정보 요청 3개는 이벤트에 남고 외부 발송은 0회다. 프로세스 중단으로 정상 종료 저장 절차가 실행되지 않아 summary, 최종 review, snapshot/ledger 내보내기 파일은 없다. 원시 이벤트와 context를 보존하고 별도 감사에서만 중단 상태를 부여했다.

최종 실패 기록이 있는 3회는 원시 usage와 요약 토큰·비용, 실제 도구 횟수, 조건별 actor, 읽은 페이지와 source_packet/retrieval 일치, snapshot에서 논리 추출 재현, ledger 이력 재생을 확인했다. 최종 제출은 없으며, 비어 있는 사실·계산 결과를 분석 성공으로 해석하지 않았다. 원래 데이터·실행·채점 자료 등 불변 667개와 보존된 소스·설계 35개, 총 702개 보존 검사가 통과했다. 0.3.1 동결 소스 사본, 신규 3개 비공개 gold, 회사 배정표 해시도 그대로다.

실행 전 별도 검사 `D5_pre_run_review_2.json`에서 B/A0 공통 설정은 condition만 달랐고 12개 무료 점검을 확인했다. 신규 gold 사전 잠금과 공개 자료 해시, 개발 6개·평가 후보 12개 분리를 확인했다. 평가 후보는 실행 등록되지 않았다.

개발자는 공통 API 이력 직렬화 문제를 확인하기 위해 배치 프로세스 중단을 보고했다. 수정 후 버전은 새로운 계획과 소스 동결을 갖춘 별도 B/A0 쌍 배치여야 한다. 이 0.3.1 시도들을 삭제하거나 새 결과로 대체해서는 안 된다. 알려진 비용과 불명 사용량은 이후 총괄에서도 버전별로 남겨야 한다.

재현: `python reports/a0_implementation/audit_d5_runs_review_2.py --partial`은 종료된 3회를 다시 검사한다. 중단 감사의 `artifact_hashes`로 중단된 시도를 포함한 81개 원본을 확인할 수 있다. 감사 생성기는 기존 감사 파일 덮어쓰기를 거절한다.
