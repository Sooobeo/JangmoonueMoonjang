# 기업별 사후 분석의 계산과 검토 기록

[37개 기업 표](기업별_37곳_결과.csv)는 최초 등록 순서대로 읽을 수 있다. 기업명, 접수번호, 원문, 사전 단계 완료 여부, 미완료 이유, 두 방식의 순위와 실제 이관 문항, 사후에 재생한 선택을 담았다. 집계에 쓰이지 않은 값은 ‘미산출’, 계산했으나 이관할 문항이 없었던 목록은 ‘없음’이다. 순위가 완성되지 않은 기업에서는 규칙 또는 공통 필수만으로 운영한 대체 경로를 별도 열에 표시했다. 순위 일치도는 표에서 소수 여섯째 자리까지 볼 수 있다.

## 계산 기준

등록 37곳 406개 문항 가운데 두 순위와 독립 기준표가 동시에 완성된 곳은 27곳 291개 문항이다. 이 중 21곳에서는 공통 필수 밖에 확정 중대 문항이 없었다. 19곳에는 판정 유보가 남아 있었다. 에이유브랜즈와 에이직랜드 두 곳에는 유보 문항도 없었다.

나머지 6곳에서 확정 중대 문항과 수용 가능·비중대 문항을 기업 안에서 둘씩 비교했다. 중대 문항이 앞서면 1, 동점이면 0.5, 뒤에 있으면 0이다. 기업 안에서는 문항 쌍의 평균을, 전체에서는 여섯 기업의 단순평균을 냈다. 67개 문항 쌍은 여섯 기업 안에서 생겼다. 기업 하나씩 제외했을 때 평균 차이는 −0.05496에서 +0.00476 사이였다. 액스비스를 제외하면 부호가 양수가 됐다.

운영 비교는 실제로 이관한 문항을 세었다. 순위 비교와 달리 확정 중대가 없더라도 무엇을 얼마나 이관했는지 셀 수 있어 27곳 모두 포함했다. 세 가족 J1은 발행사 이익, J2는 비교기업, J3은 주가·배수·주식 수·주당가치·할인 및 공모가 관련 문항이다. 확정 중대 8건은 J1 세 건, J2 다섯 건이었다. J3에는 검출 능력을 어느 쪽이 더 보였는지 평가할 확정 중대가 없었다. J2 86건에 남은 유보 60건은 회사·문항별 원자료를 보강할 필요를 보여 준다.

사후 정책은 규칙의 최상위 동점 후보 중 AI가 사람 검토로 보낸 후보만 AI 순위로 다시 정렬한다. 규칙의 단독 선두와 빈 목록은 유지한다. AI가 상위 동점 후보를 하나도 고르지 않으면 규칙의 원래 순서를 따른다. 기업별 결과와 맞춘 예외나 점수 임계값은 두지 않았다. 기존 결과를 본 뒤 정의한 정책이므로 현재 재생값은 새 표본에서 확인할 가설이다. 중대 누락 3건과 이관 문항 중 유보 8건이 남았다.

## 세 차례 검토

1. 등록 명단, 동결 순위, 문항 목록, 독립 기준표와 종료 기록을 대조했다. 37곳 모두를 추적했으며, 원본 142개 파일의 SHA-256을 [원본 지문](sources_sha256.json)에 기록했다. 등급이 완성되지 않은 기업과 순위가 완성되지 않은 기업을 구분했다.
2. [주 계산](recompute.py)은 원래 동률 가중치와 순위 순서를 적용해 기업별 점수, 실제 선택, 문항 유형 및 고정된 검토 수의 집계를 재구성한다. 동결된 결과와 점수가 일치하는지 검산한다. [독립 검산](verify.py)은 동점 집합의 중간 순위로 모든 유효 기업의 점수를 다시 구하고, 정수형 AI 점수와 후보 집합 연산으로 27곳의 사후 정책 선택을 독립적으로 확인한다. 사후 정책은 규칙 대비 9곳의 선택을 바꾸어 23건 중 중대 5건을 골랐다.
3. 표의 UTF-8 BOM, 등록번호·원문·기업명 결합, 37개 기업 전수, 문항 합계, 모든 순위 평가 불가 기업의 결측 표시를 확인했다. 각 기업 하나씩 뺀 여섯 추정치를 분수로 재검산했다. 원본 142개의 지문을 대조했다. 계산을 다시 실행해 CSV와 JSON 등 결과 파일 다섯 개가 바이트 단위로 일치함을 확인했다.

```powershell
python reports/a1_postmortem/work/statistics/recompute.py
python reports/a1_postmortem/work/statistics/verify.py
```

위 명령은 `ipo_agent_eval`에서 실행한다. 계산은 동결 원장을 읽고 이 폴더의 결과만 쓴다. 결과 전체는 [기업별 원자료](companies.json), [중대 8개 문항](material_issues.json), [집계와 민감도 분석](summary.json)에 저장된다.
