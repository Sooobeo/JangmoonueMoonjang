# R001 대행 채점과 세 차례 검증

2026년 11월 13일 한국시간, 사용자의 요청으로 Codex가 R001을 대행 채점했다. 결과는 사실 5/5, 계산 3/3, J1·J2·J3·J4 각 2점이다. 방법론적 검토 충족률은 **2점인 영역 수 4 / 전체 영역 수 4 = 100%**다. 점수 총합을 8로 나눈 지표로 바꾸지 않았다.

[최종 문서](../grading_exports/HDMS_R001_대행채점결과.docx)에 답변 문장, 공시 위치, 항목별 이유와 개선사항을 남겼다. 구조화된 기록은 `data/private/R001_proxy_grade.json`에 보관했다. 채점 결과는 공개 입력 목록이나 모델 프롬프트에 추가하지 않았다.

1. **원문과 기준 대조**: 원본 채점자료 3~5절과 HDMS 채점기준표 v0.3을 읽고 F1~F5·K1~K3·J1~J4의 기준을 적용했다. PDF 331~332·312·425쪽의 핵심 표와 주석을 이미지로도 확인했다. 입력 밖 자료에만 있는 사실을 새로운 필수 정답으로 추가하지 않았다.
2. **독립 수치 재계산**: 별도 검토자가 공통 계산 함수를 호출하지 않고 Fraction 산식으로 보존된 계산 22개와 관련 값을 확인했다. `data/private/R001_numeric_audit.py`를 실행한 결과 **86개 중 86개 PASS, 실패 0개**다. 계산 22개는 기본 15개·기준가격 1개·민감도 6개다. 일별 종가에서 네 기준시가총액을 추가 검산한 결과도 공시 표시 단위에서 일치했다.
3. **독립 기준 재검토**: 별도 검토자가 각 J의 만점 사유와 감점 반론을 확인했다. J4의 종가→기준시가총액 검산 누락도 재검토했으며, 현 기준의 명시 필수 요건으로 사후 추가하지 않고 개선사항으로 기록했다. 최종 네 인용문은 원본 답변과 문자열이 일치했고, 8개 원본 파일의 SHA256은 생성 전후와 최종 확인에서 일치했다. READY와 OPEN·비차단 요청의 의미, 점수 집계, AI 대행 표기도 대조했다.

완료를 막는 문제의 잘못된 처리, 핵심 결론을 바꿀 오류, 부당 경고는 발견하지 못했다. 다만 R001이 모든 가능한 중간 산식을 재현한 것은 아니다. 추가 검산은 채점자가 한 일이며 모델의 수행으로 소급하지 않았다. 독립 원자료 요청의 추출일·평가기준일·조정항목과 사업 차이의 영향 경로도 더 구체화할 수 있다.

세 차례는 검증 단계이며 사람 평가자 세 명을 뜻하지 않는다. 결과는 **AI 대행 채점**이고, 규리의 직접 채점·확정은 기록하지 않았다. 작업 중 실행 맥락을 확인했으므로 눈가림 채점으로 집계하지 않는다. 사람 채점 시간도 측정값을 만들지 않았다. 모델을 새로 호출하거나 원본 실행·답변·채점기준을 수정하지 않았다.

최종 DOCX는 관리형 문서 패키지의 `render_docx.py`를 통해 페이지 이미지로 렌더링했다. 이 Windows 환경에 번들 LibreOffice가 없어 native Word의 읽기 전용 PDF 내보내기와 관리형 Poppler를 연결했다. 모든 최종 페이지를 육안 확인하고 DOCX·구조화 점수·원본 보존 검사를 마친 뒤 전달했다.
