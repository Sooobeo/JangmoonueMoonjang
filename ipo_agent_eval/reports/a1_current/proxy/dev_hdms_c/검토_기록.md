2026-11-26 KST. 수정된 가림 자료로 새로운 Codex CLI 세션을 열어 7개 후보의 판단과 근거를 받았다. 실행 시간은 38.134초였고 CLI에 입력 22,302·출력 1,591토큰이 기록됐다. CLI 로그에는 반환 모델 ID와 비용이 없다. [실행 정보](audit.json) · [원본 응답](response.json)

## 세 차례 점검

1. **자료 확인.** 수정 패킷의 SHA-256을 운영자 색인과 대조했다. 실제 요청에는 가린 발행사 사업 정보, 후보별 중립 ID와 공개 근거만 담겼다. 기업명·접수번호·외부 링크·원본 항목 ID·선정 여부·채점표가 들어가지 않았는지 확인했다. [실제 요청](request.txt) · [가림 패킷](packet.json)
2. **세션 확인.** 기존 대화나 작업공간을 연결하지 않고 임시 디렉터리에서 `--ephemeral`과 `--sandbox read-only`로 실행했다. 로컬 `events.jsonl`은 새 세션 시작과 한 번의 응답 완료를 기록하며 도구 실행 항목은 0건이다. [세션 감사 기록](audit.json)
3. **연결 확인.** 7개 후보를 한 번씩 판단했고, 후보별 인용이 모두 발행사 공통 발췌 또는 해당 후보 발췌에 연결됐다. 원래 API 데이터와 대조해 두 기업 A0 및 멜콘 C가 보존됐음을 확인했다. [개발 혼합 라벨](../labels_dev_mixed.json)
