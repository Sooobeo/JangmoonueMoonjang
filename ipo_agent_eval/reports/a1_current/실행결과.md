## 본 평가 진행 판단

**이번 표본에서는 전 항목 검토를 유지한다.** 추가 검토 한 자리의 선택은 개선됐지만, 검증의 실제 이관은 두 방식 모두 4/45건이고 대행 검토 시간도 줄지 않았다. TRIZ를 보류에 적용한 한 사례에서 추가 시간과 토큰이 들었다. 운영 목록에 실제 배정된 6건의 A0·C 조합은 양쪽 문제 제기 또는 미확인 포함이어서, 양쪽 판정이 갈린 같은 유형의 반복 이관을 대상으로 하는 상호 재질문은 배정되지 않았다.

**설정한 API 모델의 확증 본 평가는 미실행이다.** 검증 4곳의 공식 A0·C는 API가 잔액 소진을 반환했다. 검증에 사용한 4곳을 제외하고 남은 기존 평가 후보 8곳의 답·기준표는 열지 않았다. 유의수준 5%, 양측 짝 비교, 검정력 80% 가정에서 표준화 효과 0.8에는 유효 기업 15곳이 필요하다. 기존 8곳이 전부 유효해도 이 가정의 검정력은 약 50%다. 같은 모델로 검증을 마치고 확보 가능한 유효 기업 수에 맞춰 목표 차이·표본·예산을 동결하는 것이 본 평가 재개 조건이다. [사전 조건](protocol.json) · [표본 산정](comparison/metrics.json)

API에서 확인한 사용량의 표준 비캐시 추정 비용은 $1.679347이다. 차단 요청의 미확인 사용량, 로그인된 Codex 세션의 비용 및 사람 시간은 합산할 수 없다. 조회 요청에는 이미 입력으로 본 원문도 들어 있다. 개발·검증 6곳에서 요청한 10쪽 중 공백을 정규화해 원래 입력과 비교한 새 본문은 5쪽이었다. 대행 CLI의 시간 상한은 호출별로 적용됐고 전체 선별 시간·토큰은 실측값이다. 대행 판정·역할·선별에는 서로 다른 세션과 모델 조건이 섞였고, 검증 4곳은 접수순으로 고른 소표본이다. 순위 향상의 범위는 이번 대행 파일럿으로 한정한다.
