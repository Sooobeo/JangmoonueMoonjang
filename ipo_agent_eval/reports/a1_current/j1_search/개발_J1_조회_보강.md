## 세 차례 검토

1. **검색 범위와 입력.** 최초 신고서 해시와 물리 쪽 수를 확인했다. 모든 페이지를 귀속 이익, 동일 기간 비교, 온기와 당반기 조정, 당·전반기 금융주석, 계절성 순으로 대조한다. 쪽 번호는 검색식에 입력하지 않았고, 공통 규칙으로 고른 페이지와 이미 제공된 페이지를 구분했다.
2. **회계 행과 산식.** 연결 귀속 이익 두 행과 연결 현금흐름표를 서로 대조했다. 조정행의 괄호는 현금흐름표에서 이익 제거를 나타내는 음수로 읽었다. 당반기 공시행의 원·천원 표시 오차가 500원 이내인지 확인하고, 전반기 금융주석을 원으로 환산했다. 표시 PER·공시 주식 수와의 곱셈·나눗셈은 `Decimal`로 실행했다.
3. **독립 후속 검토.** 원래 순위와 채점표를 가린 별도 Codex CLI 세션을 기업별로 열었다. 대상 네 항목의 전수 제출, 입력 해시와 인용 ID, 네 쪽 상한과 기존 순위 보존을 점검했다.
