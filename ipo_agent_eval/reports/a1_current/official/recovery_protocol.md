# 공식 API 복구 실험의 판정 기준

2026-11-26 KST. 개발 2곳과 검증 4곳은 이전 대행 실험에 사용한 기업이다. 운영자는 그 실험의 결과를 알고 있다. 이번 비교의 주 기준표는 당시 고정한 원본 채점이다. 같은 Terra가 별도로 원본을 채점한 결과는 기준표 선택에 따른 민감도에만 사용한다.

1. 공통 필수와 기업당 추가 한 자리, 동률 처리, 미해결 등급의 범위, 자연 중대 쟁점 정의는 기존 프로토콜을 따른다. 확정 중대 쟁점의 운영상 추가 누락 허용치는 0건이다. 추가 누락은 기업과 항목별로 따져, 다른 기업에서 새로 찾은 항목과 상계하지 않는다.
2. 기존 조회 요청은 검증 4곳 모두에서 1,100토큰 상한에 걸렸다. 복구 요청은 동일 모델·추론 강도에 기업별 항목 ID, 질문, 두 역할의 상태와 이유 앞 180자, 쪽 목록과 합의 점검 신호를 보낸다. 추가 조회는 최대 4쪽이다. 선별 결정에는 두 역할의 전체 원본 입력을 제공한다. 복구 여부, 실패한 시도와 사용량을 함께 집계한다. 원래 절차의 성공률을 따로 보고한다.
3. 점검 신호가 없는 전수 조건과 점검 신호를 받은 전수 조건은 같은 조회 방식을 사용한다. 신호가 빈 기업은 요청 내용이 동일하므로 같은 응답을 사용한다. 1차 검증에서 원본·표현 변경·근거 제거를 양쪽이 모두 통과한 항목만 보류 후보로 둔다. 공통 필수는 항상 유지한다. 검증 H1에서 추가 중대 누락이 없고 후보가 있으면 해당 기업에서 후보 전부를 제외한 선별과 전수 선별을 짝지어 탐색한다. 보류 후보 자체의 정답 등급은 선택에 쓰지 않는다. 기업별 원본 결과는 이미 대행 실험에 쓰였으므로 실험의 성격은 재검증이다.
4. 상호 재질문은 서로 비교할 수 있는 A0와 C의 판단이 갈리고, 해결되지 않은 동일 유형이 둘 이상의 서로 다른 기업의 실제 A1 목록에 이관된 경우에 점검한다. 자료 요청, 역할상 비교 불가 및 미선정 대기는 이관 건수에서 구분한다. 이미 완료된 6개 기업의 지표에는 후속 개발 변경을 소급 적용하지 않는다.
5. 모델 배정 경로를 가린 공시 심사 페르소나에 실제 이관 질문과 원문을 제공한다. 동일 기업·항목은 한 번 실측해 양쪽에 같은 값을 반영한다. 모델 서비스 시간이 포함되며 실제 사람이 참여한 분은 별도 결측으로 둔다.
