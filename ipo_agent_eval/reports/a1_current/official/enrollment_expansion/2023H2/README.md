# 2023년 하반기 DART 최초 신고서 모집

## 검토 기록

1. **검색 범위와 중복을 대조했다.** 검색 응답 10쪽이 각각 905건을 보고했고 수집한 고유 접수번호 수가 일치했다. 중단점까지 기존 18개 명부와 중복 7건, 2024년 4분기 심사 명부와 중복 2건, 해당 DART 검색에 철회 표시가 있는 최초 신고 2건을 확인했다. 적격 10개는 모든 기존 키와 대조했고 각 회사의 2014년 이후 공개 C001 조회와 공시 개정 이력에서 더 이른 지분증권 원신고가 없음을 확인했다. 10건 모두 DART 접수 시각을 분 단위로 대조했다.
2. **희망 공모가액에 실제 쓰인 방법을 재확인했다.** 적격 사례는 최초 신고서의 신규상장 목적, 발행사 실제 이익을 적용한 조항, 적용 PER, 그 상대가치를 반영한 주당 평가액 또는 공모가액 산정 문구를 확인했다. 퓨릿의 EV/EBITDA·PER 혼합 산정, 에코프로머티리얼즈의 EV/EBITDA, 블루엠텍의 PSR, 발행사 추정 이익을 쓰는 10건을 별도로 기록했다. 레뷰코퍼레이션 등 실제 이익을 조정한 사례와 캡스톤파트너스의 과거 실적 기반 두 PER 결과 평균은 확인한 방법을 그대로 기록했다.
3. **원문과 산정표를 다시 대조했다.** 공식 원본 PDF 10개의 SHA256과 공유 캐시에 복사한 파일의 SHA256이 일치했다. 적격 10건의 핵심 인용문 40개와 유투바이오 원문 회사명, 수동 제외 사유 20개의 물리 페이지 인용문을 MuPDF와 pypdf에서 모두 확인했다. 비아이매트릭스와 워트의 발행사 산정표 및 퓨릿과 에코프로머티리얼즈의 적용 방법 행을 렌더링해 표와 판정 근거의 위치를 대조했다. 유투바이오의 DART 검색 이름은 지구홀딩스이며 해당 원문 표지의 발행사 이름과 동일 법인 코드를 기록했다.

## 파일

- [eligible.json](eligible.json)에 적격 기업, DART 원신고 접수, 법인 코드, URL, PDF SHA256, 공시 시각, 물리 페이지 및 근거 인용문이 있다. PDF 10개는 `%TEMP%/ipo_a1_initial_registrations/<receipt>.pdf`에 있다.
- [chronology.json](chronology.json)에 중단점까지의 처분이 있고 [inventory.json](inventory.json)에 전체 기간의 검색 기록이 있다. PDF 후보 검색 출력과 수동 확인은 [document_screen.json](document_screen.json), [document_screen_from_46.json](document_screen_from_46.json), [determinations.json](determinations.json)에 있다. 중단점 뒤의 처리 로그는 이번 모집 집계에서 제외했다.
