## 세 차례 점검

1. 두 기업의 J1 동결 항목을 공식 A0·C 라벨과 대조했다. 보강용 원문과 계산의 해시는 앞선 조회 검증 기록과 일치했다.
2. 네 API 요청 모두의 지시문, 모델, 제공한 원문 범위와 입력 해시를 대조했다. HDMS의 두 조건은 입력 해시도 같았다. 멜콘은 추가 네 쪽과 해당 B 계산의 제공 여부를 바꿨다.
3. 네 응답에서 항목의 누락·중복, 공급된 근거 ID와의 연결 및 실제 반환 모델을 검사했다. 멜콘 M01의 조치 변화와 M02·M05의 남은 질문을 기록했다. 동결 순위는 보존했다.
