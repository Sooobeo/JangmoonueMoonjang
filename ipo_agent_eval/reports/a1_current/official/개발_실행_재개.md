# 개발 기업 Terra 실행 재개

2026-11-26 KST. 당시 잔액 소진으로 중단된 HD현대마린솔루션 C를 수정된 가림 패킷으로 재개했다. 기존 API의 두 기업 A0 원본과 멜콘 C 제출을 그대로 사용했다. HD현대마린솔루션 C는 후보 7곳의 판단을 1회 호출로 모두 제출했다. 실행 시간은 31.069초, 입력 1,115토큰, 출력 1,665토큰이었다. 기존 조기 실패와 새 제출 각각의 패킷 해시와 오류·응답을 보관했다. ## 세 차례 점검

1. **원본과 가림.** 두 기업 A0는 동결된 최초 신고서를 각각 사용했다. C에게 보낸 후보 자료는 원문 인용과 공개시점을 확인한 가림 묶음이다. 두 C 실행의 패킷 해시와 모델 요청을 대조하고, 모든 후보의 반환 ID와 인용이 일치하는지 확인했다. 원본 4개 역할의 실제 반환 모델은 모두 `gpt-6.1-terra`였다.
2. **항목과 합의 조건.** 두 기업의 원본 22개를 유지했다. HDMS C는 H02를 제외했고, H04의 방산·항공우주 사업과 H05의 장비·서비스 구성 및 성장 차이를 구체적인 반대 근거로 제시했다. 이 두 추가 검토 의견을 문제 제기로 연결하고 원판정을 보존했다. H03은 연간 서비스 비중이 부족해 미확인으로 연결했다. HDMS의 네 개 J2 후보에는 A0의 개별 수용 판정이 없었다. 멜콘 M03은 양쪽 문제 제기, M04는 C 수용과 A0 미확인이다. 두 기업에서 비교 가능한 양쪽 수용이 없어 공식 TRIZ 항목을 배정하지 않았다. [C 연결 근거](c_review_annotations.json)
3. **A1 실행과 배정.** HDMS 조회는 요청 출력 1,100토큰과 복구 요청 2,000토큰에서 각각 미완성으로 종료됐다. 두 부분 응답을 보존했다. 다음에는 원문 전체를 조회 지시문에 중복 첨부하는 대신 질문·원판정·쪽 목록만 주고 1,100토큰으로 조회했다. 이 조회와 표준 선별을 제출했다. 멜콘은 기본 조건으로 조회와 선별을 모두 제출했다. 두 기업의 요청과 응답에서 항목 전수, 인용, 고정 K와 실제 배정을 대조했다. [요청·응답과 합산 상한 검사](dev_audit.json)
