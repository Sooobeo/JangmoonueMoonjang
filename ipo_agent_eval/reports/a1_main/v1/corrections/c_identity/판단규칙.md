# C 자료의 잔존 회사명 발견에 따른 처리 기준

2026-11-27 KST. 최초 명단의 두 순위가 생성되기 전, Terra 요청 45건의 응답과 사용량이 원장에 들어온 상태에서 결정했다. 독립 채점 결과와 선별 성적은 이 결정에 사용하지 않았다.

1. 회사명을 가리기로 한 입력의 영문 상호가 원문 검토에서 발견됐다. Terra 신규 요청을 멈추고 처리 중인 세 건을 수신했다. 실제로 보낸 요청과 원문은 원래 해시에 묶어 보존한다. 이미 보낸 C 역할은 다시 시키지 않는다. 독립 채점에는 C 자료가 제공되지 않는다.
2. 전체 C 자료의 발행사·후보 본인 회사명, 제3자 회사명, 제품·브랜드 등 간접 식별 단서를 구별해 원문상의 용도와 위치를 기록한다. 직접 상호·약칭은 그 문맥의 기업을 특정할 때 표시한다. 간접 단서만으로 기업을 추정할 가능성은 별도로 남긴다. 같은 기준을 기업과 시장 전부에 적용한다.
3. 전송하지 않은 C에서 확인된 이름은 사업·제품·기간·수치와 근거 ID를 유지하면서 중립 표시로 치환한다. 치환 전후 자료와 비공개 원문 매핑, 전송 전 지문을 각각 보존한다. 선별 방식 양쪽에 같은 역할 응답을 제공한다. 본평가 기간에 가림 결함을 수정한 사실과 기존판·정정판을 사용한 기업 수를 보고한다.
4. 사전 등록한 전체 37곳 및 완료 짝·유효 짝의 분모를 유지한다. 보조 분석은 실제 송신 바이트에 ① 발행사·후보 자신의 직접 상호가 남은 기업을 제외한 집합, ② 제3자의 직접 상호까지 포함해 직접 회사명이 남은 기업을 모두 제외한 집합으로 정한다. 같은 순위 지표와 동일 가중을 적용하며 표본·추정치·구간을 나란히 기록한다. 이는 가림 결함을 발견한 뒤 정한 기술적 분석이다. 누락 기업이나 간접 식별 위험을 이유로 회사를 교체하지 않는다.
