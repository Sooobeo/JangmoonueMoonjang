# 공모가 산정 근거 검토 실험의 전체 진행 기록

이 실험은 기업공개(IPO) 신고서를 읽을 때 어떤 질문을 심사자에게 먼저 보내야 하는지 조사했다. 초기에는 한 답변의 사실과 계산을 채점했다. 이후에는 한 기업에 추가로 배정할 수 있는 검토 자리가 하나일 때 어떤 쟁점을 회수하는지 비교했다. 같은 기업이 개발 자료에 등장하더라도 서로 다른 실험의 점수와 시간은 합산하지 않았다.

## W11 독립 검토와 최종 선별 실험

1. **역할과 자료를 대조했다.** 최초 신고서를 읽은 검토자 A0와 기업 이름·실제 선정 여부를 가린 자료를 읽은 검토자 C의 판단을 같은 원본 항목에 연결했다. 사람이 추가로 살필 항목을 고를 때 규칙과 A1이 같은 두 판단을 사용하도록 했다. 초기의 고정 절차 B와 이후 공통 사전 검산 B는 해당 실험의 역할로 구분했다.
2. **같은 한 자리의 결과와 시간을 검산했다.** 개발 2곳의 22개, 검증 4곳의 45개 항목을 처리했다. 검증 단계의 독립 Codex 기준표에서 중대 쟁점은 2건이었다. 규칙은 0건, A1은 2건을 이관했다. 이관은 각각 4건이었다. 검토 페르소나의 합산 경과는 규칙 106.282초, A1 146.296초였다. 채점 모델을 바꾼 보조 분석에서는 중대 쟁점 분모가 1건으로 줄었다.
3. **설계 변경의 근거를 확인했다.** 합의 점검을 끈 A1도 검증 중대 2건을 회수했다. 합의 항목을 자동 보류했을 때 시간 절감은 관측되지 않았다. 실제 이관 6건에서 재질문을 시작할 같은 미해결 갈림의 반복은 0건이었다. 별도 문서 변형 실험은 검토한 후보에서 적격 시험본·정상 대조본 쌍이 0건이었다. 이 시험으로 오류 탐지율을 추정하지 않았다.

## W12 모집과 사전등록

1. **명단과 원문을 확인했다.** 기존 미사용 8곳, 2024년 4분기 확인분 6곳, 이후 모집에서 정해진 순서로 뽑은 23곳을 더해 37곳을 고정했다. 법인코드와 접수번호를 대조하고 37개 원본 PDF의 해시를 검증했다. 예비 8곳은 명단 밖에 두었다.
2. **판정 기준을 확인했다.** 공통 필수 밖에서 확정 중대 항목과 그 밖의 확정 항목이 모두 있어 순위를 견줄 수 있는 기업 15곳을 목표로 했다. 모집 기업 수, 두 목록과 채점표가 모두 있는 기업 수, 실제 순위 비교에 유효한 기업 수는 각각 보고하도록 했다. 같은 한 자리에서의 회수와 실제로 사람 검토에 보낸 목록도 따로 계산한다.
3. **본평가 전에 입력을 대조했다.** 공통 질문 259개, 신고서에 명시된 손익 조정 19개, 실제 비교기업 128개를 묶어 406개를 만들었다. 유진테크놀로지의 공시 중간값과 산식 간 차이로 한 항목을 양쪽 공통 필수로 지정했다. 후보 자료는 최초 신고서 공개 전에 이용할 수 있었는지 확인했다. 한국·해외 후보의 실제 선정 여부와 기업명을 가리도록 구성한 자료, 원문 인용, 채점 격리, 예산 및 복구 규칙을 점검했다. 실제 전송 뒤에는 일부 자료에서 회사 이름을 추가로 발견했다. ### 중단과 재개 뒤 반영한 사항

2026년 11월 26일에는 37곳의 원문을 모두 준비한 뒤, 24곳의 가림 자료가 입력 검사를 통과한 시점에 사용자 요청으로 멈췄다. 이 시점에는 본평가 답변이나 채점 결과가 없었다. 11월 27일 재개 뒤에는 당시 공개된 회사 자체 정기보고서를 다시 찾고, 가림 입력에 실제 제품·매출 설명이 보이는지 살폈다. 산업 일반론·표 제목만 담긴 발췌와 당시 확인한 영문명을 고쳤다. 이후 실제 역할 검토에서 다른 영문명이 발견돼 전송을 멈추고 전수 대조했다. 삼화페인트는 보관본의 대분류가 ‘정관’이었으나 원래 XML 안에 별도로 실린 사업·제품·매출 절을 찾아 복구했다. 하나머티리얼즈는 해당 접수의 원본 보고서 본문 절을 확보해 표지와 연결했다.

Terra는 모델 제공 여부와 원장의 동시 비용 예약, 오류 시 전송 중단 및 재개를 확인했다. Codex 채점은 첫 채점이 실패해도 독립된 두 번째 채점을 시도하며, 두 번 모두 유효한 항목을 조정 전 일치율의 분모로 삼는다. 이관 시간은 목록을 만든 뒤 서로 다른 항목을 한 번씩만 측정한다. 세부 검사와 수정 근거는 각 단계 기록에 남겼다. [실행기 검토](v1/terra_review.json) · [대행 시간 검토](v1/timing_preflight_review.json) · [가림 자료 전수 대조](v1/c_content_review.json)

공통 검산 파일 37개를 별도로 읽어 406개 항목의 가격 영향 입력을 합산했다. 적격 대안의 절대 변화율을 제공한 항목은 23개(이익 기간·조정 등 J1 19개, 산식 등 J3 4개)였다. 비교기업 128개 항목에는 이 단계에서 수치화한 적격 대안이 없었다. 공통 필수는 1개다. 이는 순위를 매기기 전에 준 정보량으로, 어떤 항목이 나중에 중대로 채점됐는지는 독립 채점표에서 확인한다.

### 본평가 시작 직후의 실행기 정정

원본 입력 2,164개 파일을 동결한 후 첫 5곳의 Codex 채점에서 CLI가 모델 응답 전 표시한 로컬 기능 안내를 실행기가 도구 사용으로 오인했다. 14건의 응답을 보존한 채 신규 전송을 일시 중지했다. 이때 Terra는 이미 예약한 12건의 응답과 사용량을 전부 보존했다.
