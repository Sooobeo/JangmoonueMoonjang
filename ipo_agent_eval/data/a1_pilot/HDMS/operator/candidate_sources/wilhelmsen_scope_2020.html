    Reporting scope

    Companies in which Wilh. Wilhelmsen Holding ASA (Wilhelmsen) owns more than 50% are included in the scope of this report.
    15. Mar 2021

     

    Significant changes to the reporting scope for this period

    There have been no significant changes to the entities included in the scope of this report for 2020. 

    Entities included in the 2020 report

    Wholly owned entities and entities where Wilhelmsen has majority ownership are included in the report:

    • Ship Management, which provides full technical management, crewing and related services for all major vessel types.
    • Ships Service, which has the world’s largest maritime network supplying products and services focusing on marine chemicals and products, maritime logistics, and ships agency.
    • Insurance Services, which provides marine and non-marine insurance solutions.
    • NorSea Group, which provides logistic support to offshore activities anywhere in The North Sea basin and beyond.
    • WilNor Governmental Services, which provides military logistic services in Norway and internationally.
    • Raa Labs, which delivers infrastructure and services to digitalize vessels and operations.

    Corporate services are also included in this report.

    Entities not included in the 2020 report

    The shipping and land-based logistics, and other interests not wholly or majority owned are not included in this report:

    • Wallenius Wilhelmsen ASA (37.8%)
    • Hyundai Glovis (11% through Treasure ASA)
    • Qube (1.8%)
    • Massterly (50%)
    • Dolittle (46%)
    • Edda Wind (25%)
