# IPO 당장 할 일

갱신: 2026년 11월 13일. 담당은 규리이며 자료 조사·구현·실행·채점은 Codex가 지원했다.

**승인한 멜콘·디티에스 준비, B 실제 실행, 채점 및 세 차례 검증을 마쳤다.** 기존 HDMS를 포함한 개발용 3기업 파일럿의 입력·기준표·실행·채점 기록이 갖춰졌다. 사람의 직접 채점이나 최종 평가 완료를 뜻하지 않는다.

## 완료한 일

- [x] 기존 HDMS 입력·PDF·실행·채점 등 122개 파일의 SHA256을 기록하고 변경 없음을 확인했다.
- [x] 멜콘 2026-09-29 정정 투자설명서 600쪽과 디티에스 2026-10-12 정정 투자설명서 719쪽을 확보했다. 접수 이력·청약 전 여부·자료 마감을 대조했다.
- [x] 전체 1,319쪽을 사례별 폴더로 분리해 저장하고 본문·표·주석·물리 쪽과 인쇄 쪽을 대조했다.
- [x] 실제 답변 전에 두 기준표를 작성하고 독립 계산을 대조한 뒤 해시를 고정했다. 답변 후 기준표 변경은 없다.
- [x] 등록 사례 선택, 사례별 보고서 제목, 공통 방법서 분리, HDMS 전용 검색 연도 제거를 구현했다.
- [x] 합성 사례 격리·비공개 정답 및 기존 답변 미노출·변조와 페이지 누락/중복 거부 등 회귀 테스트 146개를 통과했다.
- [x] 세 사례를 무료로 점검했다. 새 실제 답변 전에 입력 크기를 근거로 목표를 16만 토큰으로 조정하고 이유와 버전을 기록했다. 실행당 0.30달러·출력 1.6만·600초 제한은 유지했다.
- [x] 멜콘·디티에스의 실제 Terra 답변을 각각 한 편 받아 원본 요청·응답·계산·사용량과 상태를 보존했다. 두 실행은 SUBMITTED / PENDING_INFO다.
- [x] 고정 기준표로 채점하고 별도 AI 재검토로 확정했다. 단계별 경과 시간과 추가 비용 약 472원을 남겼다. 사람 작업시간은 미측정으로 유지했다.

연환산·조정은 이번 버전에서 기존 period·description·J1 사실 필드로 표현했다. 별도 계산 스키마를 새로 만든 것으로 기록하지 않는다. 실제 실행에서 확인된 주식수 구성의 한계는 아래 첫 작업으로 남긴다.

## 결과와 세 차례 검증

| 사례 | 사실 | 계산 | J1~J4 | 주요 미충족 |
|---|---:|---:|---|---|
| HDMS — 기존 결과 | 5/5 | 3/3 | 각 2점 | 기존 검증 기록 참고 |
| 멜콘 | 5/5 | 2/3 | 각 2점 | 자동 주식수 합계에서 의무인수75,000주 누락, 서술과의 충돌 미해결 |
| 디티에스 | 4/5 | 3/3 | 각 2점 | 구주매출0 확인 누락. 잘못된 자동 합계는 모델이 명시적으로 배제 |

방법론 충족률은 세 사례 모두 `2점인 J 항목 수 / 4 = 100%`다. 전체 정답률이나 모든 계산의 정확성을 뜻하지 않는다. 기존 HDMS는0.1.4, 신규 두 사례는0.2.1 설정이므로 동일 설정의 통제 비교로 해석하지 않는다.

1. **원문 검증:** 접수·정정 이력과 표 이미지를 확인하고 새 원문1,319쪽을 전수 대조했다. 기존122개 파일을 보존했다.
2. **숫자·채점 검증:** 답변 전 독립 숫자검사227개를 통과했고, 답변 후에는 실제 산출물 전체를 항목별 채점하고 별도 재검토했다. 발견한 오답을 고쳐 쓴 뒤 채점하지 않았다.
3. **구현·기록 검증:** 회귀 테스트146개와 실제 실행 후 독립 프로토콜 검사318개를 통과했다. 기준표·코드·입력28개 동결 파일과 원본 실행의 보존을 확인했다.
