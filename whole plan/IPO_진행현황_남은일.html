별도의 평가 과정

사실·계산의 정확성목록 밖 실제 중대 쟁점공동 미탐·오경보사람 검토량·모델 비용

예를 들어 이익의 기간이 맞는지, 비교기업의 사업 차이가 배수 선택에 반영됐는지, 가정을 바꾸면 결과가 얼마나 달라지는지를 봅니다. 완료라고 제출한 답에 오류가 남았는지, 불필요하게 검토를 미뤘는지도 함께 평가합니다.

초기 3기업 파일럿 뒤 개발 사례를 6기업으로 늘렸습니다. 최초 B/A0 비교에서 드러난 전송·예산·출력 계약 문제를 고쳐 v0.4.3-dev까지 진행했습니다. 최신 HDMS 두 실행은 등록·계산·민감도·제출을 통과했지만, 전체 배치와 최종 검토는 아직 끝나지 않았습니다.

연구 제안서·설계서·실험 프로토콜, 공통 검토 방법서와 기업별 기준표를 준비했습니다. 사실·계산·판단을 나누어 평가합니다.

B와 자율 선택 A0를 연결했습니다

같은 공개 자료·도구·계약 위에서 B는 고정 순서, A0는 모델 선택으로 실행합니다. 새 실행마다 원본 요청·응답·호출 주체·사용량·실패를 남깁니다.

개발 6기업과 평가 후보 12기업을 분리했습니다

개발용은 HDMS·멜콘·디티에스·신성에스티·에이엘티·밀리의서재입니다. 전체 공개 입력과 분리된 기준표를 준비했고, 평가 후보는 적격성과 원문을 확인했습니다.

사실·선택·계산·근거를 연결했습니다

공시 직접값·파생값·미확인·0, 주식수 포함·제외와 적용 분모를 구별합니다. 계산에 쓴 입력 상태를 고정하고 최종 답변이 실제 계산 결과를 사용했는지 검증합니다.

실제 실패를 재현하고 공통 실행기를 고쳤습니다

API 응답 재전송, 탐색·최종화 예산, 출력 절단, 공유 스키마 오염, 명시 분모 선택, 비교기준 중복 표기와 주장 ID 충돌을 보완했습니다. 기존 답변과 실패 원본은 보존했습니다.

최신 HDMS 두 실행의 실제 경로를 확인했습니다

B·A0 모두 입력 등록 후 현재 상태의 일반 계산 24개와 민감도 7개가 OK였습니다. 최종 제출·근거·요청 원장·사용량 검사도 통과했습니다.

현재 실험 응답 모델은 GPT-6.1 Terra, 추론 수준 medium입니다. Codex는 구현·자료 정리·AI 보조 검토를 지원했습니다. 독립된 사람 채점, A1 구현, 최종 평가 설정 고정과 새로운 기업의 본 평가는 남아 있습니다.

최신 버전은 어디까지 실행했나

FIX_v043 · 0.4.3-dev
6기업 × B/A0 각 1회, 총 12회 계획입니다. 사용자 중단 요청이 전달될 때 다음 기업인 멜콘은 자동 대기열에서 이미 시작된 상태였습니다. 실행 프로세스를 종료하고 아래 상태로 보존했습니다.

제출 성공과 검토 업무의 완료는 구분합니다.

HDMS 두 답변은 모두 추가 정보 대기(PENDING_INFO)입니다. 핵심 계산과 실제 실행 경로는 통과했지만 환율 변환의 계약 범위, 공시 표시 전 정밀도 등의 확인사항이 남았습니다. 이 한 기업의 결과로 B/A0의 우열이나 전체 보완 성공을 판단하지 않습니다.

HDMS에서 이번에 확인한 개선과 남은 한계

v0.4.2 B는 같은 평가표의 비교기준을 서로 다른 문구로 선언해 주당 계산과 민감도가 INVALID였습니다. v0.4.3에서는 모델이 공통 비교기준을 선언해 참조하도록 표현을 바꿨고, 이번 B·A0 모두 핵심 수치 계산에 성공했습니다. 엄격한 기준 검사는 유지했습니다.

B의 계산 K1~K3는 모두 인정됐고 구조화 사실 9개는 원문 지지를 확인했습니다. B의 F/J 전체 채점과 최신 A0의 내용 채점 기록은 완료 전이므로, 두 조건의 전체 품질 비교표로 합산하지 않습니다. 해외 비교기업의 현지 주가·환율은 원문에 있으나 허용 계산식의 환율 변환 표현이 부족한 점을 별도로 남겼습니다.
