IPO 공시를 검토하는 AI,
어떤 절차가 더 정확한가?

실제 기업의 IPO 공시를 AI가 읽고, 숫자를 다시 계산하고, 판단의 근거와 남은 확인사항을 설명하게 합니다. 같은 모델에 서로 다른 업무 절차를 붙여 검토 품질·남은 오류·비용이 어떻게 달라지는지 비교하는 연구입니다.

전체 프로젝트는 이렇게 구성됩니다

구조는 검토 시스템을 만드는 부분과 그 결과를 평가하는 부분으로 나뉩니다. 공통 자료와 도구 위에서 B·A0·A1을 비교하고, 결과는 별도의 기준표로 채점합니다.

별도의 평가 과정

검토 결과 + 사례별 채점 기준표

기준표의 답은 모델에 제공하지 않습니다. 가능한 범위에서 조건명을 가린 결과를 같은 기준으로 채점합니다.

사실·계산의 정확성근거와 판단의 연결완료·보류·남은 오류API 비용·실행 시간

예를 들어 이익의 기간이 맞는지, 비교기업의 사업 차이가 배수 선택에 반영됐는지, 가정을 바꾸면 결과가 얼마나 달라지는지를 봅니다. 완료라고 제출한 답에 오류가 남았는지, 불필요하게 검토를 미뤘는지도 함께 평가합니다.

실험 응답 모델은 GPT-6.1 Terra이며, Codex는 프로그램 제작과 자료 정리·검증을 지원했습니다. 현재 채점은 AI 보조와 별도 AI 재검토입니다. 독립된 사람 채점과 최종 평가용 기준·설정 고정은 아직 남아 있습니다.

04

여기까지 진행한 파일럿의 결과

핵심 판단을 설명하는 능력은 확인했습니다. 동시에, 최종 답변에 남은 오류와 못 찾은 사실도 확인했습니다.

기업사실계산J1~J4 판단검토 상태
HD현대마린솔루션기존 실행 · 0.1.4-pilot5 / 53 / 3각 2점 / 2점READY완료를 막는 요청 없음
멜콘신규 실행 · 0.2.1-pilot5 / 52 / 3각 2점 / 2점PENDING_INFO추가 정보 확인 필요
디티에스신규 실행 · 0.2.1-pilot4 / 53 / 3각 2점 / 2점PENDING_INFO추가 정보 확인 필요

J1 적용 이익 · J2 비교기업 · J3 대안 계산의 영향 · J4 확인 범위와 다음 행동. 세 답변 모두 제출 자체는 성공했습니다.

“방법론 충족률 100%”는 전체 정답률 100%가 아닙니다.

이는 네 판단 항목이 모두 2점이라는 뜻입니다. 사실·계산 점수는 별도입니다. READY도 정답을 보증하지 않으며, 추가 정보 대기 상태와 점수는 서로 다른 기록입니다.

멜콘: 말로 쓴 구성과 자동 계산 결과가 달랐습니다

서술에서는 의무인수 75,000주를 포함한 네 항목을 정확히 적었습니다. 하지만 자동 합계는 이 75,000주를 빠뜨렸고, 최종 답변에서 충돌을 해소하지 않았습니다. 그래서 사실은 5/5, 계산은 2/3입니다.

프로그램이 만든 계산행의 문제와 모델의 사실 독해를 구별해 기록했습니다.

멜콘 채점 근거 · 실제 답변
디티에스: 잘못된 자동 합계는 배제했지만, 구주매출 0주를 확인하지 못했습니다

자동 계산은 제외해야 할 옵션을 더하고 추가인수를 빠뜨렸습니다. 모델은 그 결과를 사용하지 않겠다고 명시하고 올바른 합계를 제시했으므로 계산 K1을 인정했습니다. 계산 첨부 자체는 여전히 보완해야 합니다.

전체 공시에는 구주매출이 없는 근거가 있지만 실제 전달된 34쪽에서 찾지 못해 미확인으로 남겼습니다. 이 사실 누락으로 사실 점수는 4/5입니다.

디티에스 채점 근거 · 실제 답변
이 세 기업의 점수로 아직 말할 수 없는 것

세 기업은 시스템을 개발하면서 본 사례입니다. 최종 평가용으로 다시 쓰지 않습니다. HDMS는 이전 설정, 새 두 기업은 변경된 설정이므로 현재 점수표는 동일 조건의 통제 비교가 아닙니다.

현재 채점은 AI 보조와 별도 AI 재검토입니다. 독립된 사람 채점이나 조건명을 가린 최종 채점까지 끝났다고 집계하지 않습니다.
