3.2 확보 규모와 평가 표본

기존 작업으로 개발 6기업과 평가 후보 12기업을 분리했다. 당시 적격성은 최종 문서의 과거실적 PER 기준이었다. A1에서는 양쪽 기업의 최초 신고서에서 적격성을 다시 확인하고 원본 입력과 기준표를 준비한다. 개발 파일럿에서 자연 중대 쟁점 빈도, 공통 필수 항목을 뺀 쟁점, K 경계에서 교체된 기업 수와 자료 제작·채점 시간을 재어 평가 규모를 정한다. 모집·배정 기록

3.3 모집·분할 절차

  1. 모집대장의 기존 배정과 제외 근거를 사용한다. 추가 모집은 DART·KIND의 최초 신고서로 동일 기준을 적용하고 조사 기간과 입·제외 근거를 기록한다. R02
  2. 팀이 개발에서 자세히 분석한 기업은 개발 묶음에 둔다. 평가 후보는 최초 신고서, 당시 가용 자료, 비교기업 원천과 문서 중첩을 확인한다.
  3. 연간·LTM·중간실적 연환산, 국내·해외 비교기업, 시장 구분을 기록한다. 필요 표본을 정한 이유와 기준표 역할 분리를 평가 출력 생성 전에 확정한다.

3.4 작업량에 따른 규모 선택

12기업 안팎이면 카나리 신호의 독립 기업 수가 제한된다. 파일럿의 자연 중대 쟁점 빈도, 순위 교체 기회, 변형 제작 시간, 검토당 모델 비용으로 규모와 운영 모드를 산정한다. 두 조건은 같은 원본과 공통 필수 항목을 사용한다. 기업별 목표 추가량 K는 공통 필수를 제외한 순위 대상 수를 넘지 않게 적용한다. K, 실행 중 중대성 기준, 정렬 규칙 및 평가용 심은 쟁점의 사용 여부를 결과 확인 전에 고정한다.

기존 120회·72회는 고정 절차 B/A0/A1을 반복 비교하던 v2 예산 산식이다. A1은 세 목록 조건과 모델 실행 수를 구별하여 8.6절로 새로 계산한다.

최초 신고서의 공개 시각을 확인할 수 없으면 date_precision=DATE로 기록하고 해당 신고서와 이전 날짜의 검증된 자료를 사용한다. 공개 시각이 확인된 경우 같은 날의 추가 자료는 신고서 공개 전 또는 동시에 이용 가능했음을 확인한 경우에만 허용한다. 공개 순서를 확인하지 못한 자료는 제외 사유를 남긴다. 주가 기준일 이전의 지식만 필요한 주장에는 그 시점의 제한도 적용한다.

기존 개발 문서와 사후 비교용 정정본에서는 section_state=BEFORE / AFTER / CURRENT / UNKNOWN을 보존한다. A1 입력에는 최초 시점 이후 정정본이 혼입됐는지 확인한다.

4.6 문서 가공

  1. 원본 bytes와 SHA-256을 보존한다.
  2. XML·PDF에서 텍스트와 표를 추출하고, 표의 단위·헤더·주석을 함께 저장한다.
  3. 검색 chunk에 문서 ID, 페이지, 표 제목, 구획, 시점, 회사명·연결 범위를 붙인다.
  4. 일반 본문은 약 800–1,200토큰을 초기 목표로 나누되, 표와 주석은 가능하면 분리하지 않는다. 큰 표는 행 묶음으로 나누고 헤더를 반복한다.
  5. 전처리 규칙은 개발 자료에서 결정하고 최종 평가에 동일 적용한다.
  6. 사람은 깨진 OCR·표 구조를 원문과 대조해 고칠 수 있지만, 정답을 암시하는 해설은 입력에 추가하지 않는다. 변경을 모두 기록한다.
  7. 실험 실행 중에는 인터넷을 직접 검색하지 않고 고정된 문서 저장소만 사용한다. 자료 수집 단계의 웹 검색과 모델 실행 단계의 정보 접근을 구별한다.

OpenDART는 공식 원문 확보의 시작점이다. 원문 XML이 있다고 모든 판단 항목이 자동 구조화되는 것은 아니다.R02

6. 원본 기준표와 참고자료 카드

6.1 작성과 채점의 기본 원칙

규리가 원본 기준표 작성·검토·최종 채점을 담당한다. 모델 답변을 받기 전에 원본 전체의 항목 ID를 정한다. 모든 항목에 원문 위치, 사례의 사실, 허용 판단과 판정 근거를 붙인다. 두 AI가 모두 언급하지 않은 항목도 목록 후보와 원본 채점에 남긴다. 원본 기준표와 시험 정답은 모델·검색 인덱스·카나리 제작에 제공하지 않는다. 현실적인 카나리는 두 사람이 각자 판정 가능성과 중대성을 확인하며, 여건에 따라 원본 판단의 일부를 독립 2차 확인한다.

문헌의 원칙과 연구자의 운영규칙을 분리한다. 예를 들어 이익 정의를 일관되게 비교한다는 것은 문헌의 원칙이다. 0·1·2점, 필수 제출 항목, 추가 검토를 요청할 조건은 이 연구의 운영규칙이다. 자료에 없는 ±5%, 특정 국가·업종의 무조건 제외 규칙을 문헌의 결론으로 만들지 않는다.

6.4 C0 사실과 계산 카드

볼 자료: 사례의 산정표·표 주석·주식수 표, R18의 Definitional Tests.

확인 순서: 원문 값과 단위 → 이익 기간·지배주주/전체·연결/별도 범위 → 산식 → 주식수 → 표시 정밀도. 공시값 재계산과 독립 원천 확인은 L1/L2/L3로 나눈다.

  • 충족: 필수 값과 정의를 정확히 추출해 계산하고 결과 차이를 정밀도 규칙에 따라 설명했다.
  • 미충족: 다른 표의 단위를 그대로 섞거나 구주를 신주처럼 더하는 등 재계산이 틀렸다.
  • 판정 보류 예: 원래 시장가격을 확보하지 못했다면 그 값의 진실성은 미확인으로 남기되 공시값의 산술은 평가한다.

이 카드는 사실·계산 지표에 사용한다. J1–J4 판단 점수와 중복해 하나의 종합점수로 섞지 않는다.

6.5 J1 적용 이익 카드

볼 자료: R17 Summary의 이익 정의·정상화 설명. 정상화 가정이 실제 쟁점이면 R19의 규모 변화·회복 시점. 사례의 이익 산정표·조정 주석.

사례별 미리 기입할 답: 적용 기간, 연환산 산식, 조정 항목과 금액, 발행사와 peer의 이익 기준 차이, 해당 공시에 제시된 이유와 미확인 전제.

점수 판정 예시
2 정의·기간·조정을 정확히 구분하고 비교에 주는 영향·제약을 근거로 설명. 필요한 확인을 구체화
1 반기 연환산·조정 사실은 맞지만 그 가정이나 비교상 제약의 설명이 불완전

점수 판정 예시

2 기본값·대안·변경 이유가 명확하고 계산이 맞으며 변화의 방향·크기와 해석을 설명

0 근거 없는 새 숫자를 실제 사실처럼 사용하거나 계산·변화 방향이 틀림

공시가 이미 제시한 대안도 사용할 수 있다. 이 경우 재계산·영향 설명으로 채점하고 새로운 발견으로 포장하지 않는다. 차이가 작다는 결론도 인정하며 임의의 합격 오차를 추가하지 않는다.

6.8 J4 다음 행동 카드

볼 자료: 앞 카드에서 확인된 사실·자료의 부재·계산 영향. 이 카드의 요청·우선순위 판정 규칙은 본 연구가 정의한다.

사례별 미리 기입할 답: 이미 해결 가능한 쟁점, 필요한데 없는 자료, 공개 근거 충돌, 각 쟁점이 막는 결론, 허용 요청의 구체적인 예.

추가 사람 검토는 동일한 문헌·공시를 더 확인할 필요가 있다는 요청이다. 요청의 필요성을 기준표로 판정할 수 없으면 그 항목을 GOLD_UNRESOLVED로 표시한다. 실제 전문가 필요성이나 실제 해결 성공을 측정했다고 쓰지 않는다.

6.9 작성·고정·채점 순서

  1. 규리가 원문에 기반한 공통 방법서와 원본 항목 ID를 준비한다. 원본 항목과 하위 유형의 연결, 기업·유형별 교차 채점 표본을 사전에 고정한다.
  2. 규리가 각 기업의 원본 항목을 채점하고, 두 사람은 표본에 포함된 원본 판단형 항목을 각자 독립 채점한다. 두 사람 모두 원문과 공통 기준을 사용하고, 카나리·모델 답변·두 검토 목록은 가린다. 각자의 판정과 근거를 기록한 뒤 원문으로 불일치를 조정한다. 합의하지 못한 항목은 판정 유보로 남긴다. 원본 기준표를 확정한 뒤 두 사람이 카나리 자료를 함께 확인한다.
  3. 개발 자료에서만 판정 예시와 운영규칙을 다듬고 최종 평가 전 고정한다.
  4. 프로그램이 조건명·반복·실행 순서를 무작위 익명 ID로 바꾼 채점 사본을 만든다.
  5. 규리가 카드별로 채점하고 근거·점수 사유를 기록한다.
  6. 익명 ID를 조건과 다시 연결해 집계한다.

기존 보고서의 보조 채점에서는 조건명을 가려도 문체·검증 흔적에서 조건을 추측할 수 있다. A1의 원본 기준표에는 출처·원문 대조 사유와 함께 독립 2차 채점의 표본 범위, 일치·불일치, 조정 근거와 판정 유보 사유를 기록한다.

새롭고 타당한 지적은 기본 점수와 별도 기록한다. 기준표 오류를 수정하면 모든 조건·반복에 동일 재채점하고 원래 점수·사유·수정 영향을 보존한다. 최종 평가 후 규칙을 넓혀 만든 결과는 보조 분석으로 구분한다.

6.10 점수·판정 불가·핵심 오류

기존 보고서의 보조 채점에서 2점은 기준 충족, 1점은 부분 충족, 0점은 미충족이다. 충족률은 2점 항목의 비율이며 부분점수는 별도 진단이다. J1–J4 영역별 결과를 함께 보이고 비용·요청을 가중 합산하지 않는다.

항목별 0·1·2점 채점에서 NA는 GOLD_UNRESOLVED에 사용한다. 통계 지표에서는 분모가 0인 경우에도 NA를 사용하되 사유를 구분한다. 유효 항목이 없는 영역이 있으면 해당 기업의 방법론적 검토 충족률은 모든 조건에서 NA로 처리하며 남은 영역만 재평균하지 않는다. 그 기업도 오류·실패·비용 등 가능한 지표에는 남긴다. 판정 불가 비중과 사유를 함께 보고한다.

핵심 검토 오류는 사례의 필수 결론을 바꿀 수 있고 원문·산식·명시된 기준과 충돌하는 오류다. 존재하지 않는 근거, 정정 전 수치의 현재값 사용, 이익 기간 혼동 등이 해당할 수 있다. 기존 보고서의 보조 채점에서는 사례별 오류와 영향을 미리 적고 참고자료에 따라 판정한다.

7. 계산 도구와 숫자 허용 오차

7.1 기본 산식

단순화하면 다음과 같다. 실제 사례는 원문이 정의한 항목·조정·주식수를 따른다.

주주지분 평가액(평가 시가총액) = 적용 순이익 × 적용 PER
주당 평가가액 = 주주지분 평가액 ÷ 적용 주식수
희망 공모가 = 주당 평가가액 × (1 − 할인율)

PER로 산정한 값은 주주지분가치이며, 부채 등을 포함한 EV와 구별한다.

신주 발행, 구주 매출, 옵션·전환권, 추가 인수 주식의 반영은 원문과 계약 조건을 확인한다. 구주 매출을 신주 발행처럼 더하지 않는다. 배수 평균의 대상·가중 방식도 원문을 따른다.

7.2 숫자 판정 순서

  1. 단위와 통화, 기간, 이익의 범위부터 맞춘다.
  2. 공개된 원시값이 있으면 그 값으로 계산한다.
  3. 표시된 값만 있으면 반올림·절사 규칙을 확인한다.
  4. 규칙을 알 때 입력의 가능한 정밀도 구간을 전파하여 결과 범위를 구한다.
  5. 규칙을 모르거나 원천값이 없으면 “정밀도 설명 가능/미확인”을 구분하고 즉시 오류라고 단정하지 않는다.
  6. 계산 차이와 경제적 타당성은 별도 채점한다.

예를 들어 최근접 반올림으로 소수 첫째 자리까지 제시된 31.5의 가능한 원래 값은 통상 31.45 이상 31.55 미만이다. 그러나 실제 문서가 같은 반올림 규칙을 사용했다는 확인 없이 이 구간을 절대적인 사실로 쓰지 않는다.

7.3 도구 초기 기능

정확한 소수 연산, 단위 변환, 합계·비율·PER 계산, 공시된 이익 조정 재현, 연환산과 LTM 구분, 표기 정밀도 검사, 공개 peer 배수의 평균·중앙값·제외 민감도.

계산기는 모델이 준 숫자를 정확히 계산할 뿐 그 숫자가 원문에서 맞게 뽑혔는지는 보장하지 않는다. 계산 결과에는 입력 출처 ID도 남긴다.

8. 에이전트와 기준선 구현 계약

8.1 공통 입력과 공통 도구

기존 A0와 고정 절차 B는 공통 입력·도구 계약을 사용했다. A1의 각 역할에는 case_id, 최초 공개 시점, 공통 방법서와 역할별 허용 목록만 제공한다. A0는 산정표를 읽고 기존 보고서를 제출한다. 독립 검토자 B는 별도의 가림 자료와 후보별 출력 계약을 사용한다. 항목별 대조 기록은 A0 원본 보고서와 분리한다. 사례별 평가표와 시험 정답은 두 역할의 입력에서 제외한다.

8.2 기존 개발의 고정 절차 B

아래는 고정 절차 B의 개발 계약이다. 실행 버전별 구현과 결과는 당시 기록을 참조한다. A1의 독립 검토자 B는 8.4절에서 정의한다.

다음 순서를 코드로 고정한다.

  1. 문서 목록·버전·기간 확인.
  2. 고정된 질의 묶음으로 가치평가표·주식수·적용 이익·비교기업 자료 조회.
  3. 정해진 추출 양식 작성.
  4. 추출값을 계산 도구로 재계산.
  5. J1–J4 체크리스트 순서로 검토.
  6. 동일 출력 양식으로 제출.

질의는 기업명·문서 제목 등 메타데이터를 채워 만드는 방식으로 고정한다. 모델이 임의로 계획을 바꾸거나 검색을 반복하지 않는다. 내부 도구·산출물은 A0와 같으며 B도 미확인·정보 요청·이관을 보고할 수 있다.

8.3 A0: 기본 에이전트

공통 방법서·과제·도구를 주고 모델이 다음 행동을 선택한다. 사례별 정답 힌트·검사기 피드백을 제공하지 않는다. 공통 형식 검사와 계산 도구는 사용할 수 있으며, 불확실성을 표시하고 정보 요청·이관할 수 있다.

8.4 A1의 사실·계산 검사, 독립 검토 및 카나리

A0는 기존 계약으로 보고서를 제출한다. 보고서 확정 뒤 공통 항목 대조기가 미리 정한 원본 항목별로 A0의 명시적 판단과 인용을 연결한다. 같은 A0 원본 보고서와 대조 결과를 두 핵심 비교에서 재사용한다. 별도 검증 결과와 수정 제안은 사례 ID와 원본 제출 ID에 연결한다.

2층. 독립 검토와 원본 대조

  1. 최초 공개 시점에 확인할 수 있던 업종·사업·자료 가용성으로 독립 후보군을 만든다. 최종 선정표로 후보군을 제한하지 않는다. 실제 선정 후보, 현실적 카나리와 정상 후보가 들어가는 표준 후보 묶음을 확정하고, 원본과 변형본의 B 실행에서 동일한 정보·양식·중립 ID를 쓴다. 포함에 필요한 후보가 독립 기준을 충족하지 않으면 타당한 시험을 구성하지 못한 사유를 기록한다.
  2. B의 후보별 결과는 candidate_id, 포함·추가 검토·제외, 사유와 구체적인 근거 위치를 담는다. 적용 이익·배수 집계도 제안값 또는 미확인과 근거를 담는다. 원본의 최종 비교기업·선정 사유·적용 이익·배수 집계 방식·평가표와 시험 목표는 해당 역할에서 숨긴다. 본문, 제목·파일명, 메타데이터, URL, 검색 결과, 인접 페이지를 점검한다. 외부 검색과 허용 목록 밖 자료 접근을 막고, 실제 전달된 묶음과 반환 문서를 저장한다.
  3. 대조기는 고정 원본 항목별로 수용·문제 제기·미확인을 분류한다. 해당 선택을 근거로 명시 수용하면 수용으로 기록한다. 여러 비교기업을 한꺼번에 적절하다고 적은 A0 문장은 개별 후보의 수용으로 세지 않는다. 근거 있는 제외·추가 검토 또는 원본 선택을 반박하는 대안은 문제 제기로 기록한다. 원본과 양립 가능한 대안만 제시하고 원본 선택에 명시적 판단을 내리지 않았거나, 판단 또는 근거가 빠졌으면 미확인으로 둔다. 답변에 근거와 판단이 연결된 후보와 전체 판단 대상 후보 수를 검토자별로 기록한다.
  4. A0는 원본·카나리·정상 대조를 각각 한 번 새 세션에서 순서를 섞어 검토한다. 가림형 B는 발행기업마다 공통 후보 풀을 한 번 독립 검토하고 그 답변을 잠근다. 채점기가 이 기업의 같은 B 답변에서 해당 후보 판단을 찾아 각 A0 답변과 연결한다. 다른 발행기업에는 B 답변을 재사용하지 않는다.
  5. 채점기는 숨겨 둔 후보와 하위 유형으로 각 시험을 판정한다. 근거가 있는 후보별 차이를 특정해 제외·재검토를 요청하거나, 차이를 인정하고 포함 근거와 민감도를 제시하면 판단형 탐지로 기록한다. 유효한 응답에서 자료가 주어진 대상의 판단을 빠뜨리면 미탐이다. 자료 부족이나 전체 응답 무효는 채점 불가로 남긴다.

가림의 효과를 별도 확인할 경우 같은 B 모델·후보 묶음·질문·채점 기준으로 선택의 공개 여부만 바꾼 대조 실험을 사전 지정한다. 다른 모델을 비교하는 실험은 별도 보조 분석으로 기록한다.

공동 미탐률과 순위

기업·사전 정의 하위 유형별로 서로 다른 현실적 카나리마다 그 변형본의 A0 답변과 해당 후보에 대한 기업 공통 B 판단을 하나의 채점 짝으로 연결한다. 양쪽을 모두 채점할 수 있으면 유효 쌍이다. 두 AI가 같은 시험을 놓친 쌍을 유효 쌍 수로 나누고, 유효 쌍 2개 이상에서 공동 미탐률이 50% 이상일 때만 같은 기업·하위 유형의 공동 수용 항목을 올린다. 유효 쌍이 2개 미만이면 신호 미확인으로 두고 기본 순위를 사용한다. 같은 기업의 여러 짝은 B 답변을 공유한다. 같은 B 입력 또는 같은 A0 변형본을 다시 실행한 결과는 민감도 분석에 쓰고 주 신호 집계에서는 제외한다.

그 밖의 항목, 신호 기준 미충족·미확인기본 순위 적용. 판정·자료 미확인은 이유와 필요한 자료를 남김

두 목록에 같은 공통 필수 검토를 넣고 기업마다 남은 항목에서 목표 K개까지 추가한다. 한쪽의 원본 응답 전체가 무효이면 해당 검토자의 원본 판단을 미확인으로 두고, 확보한 공통 근거와 기본 정렬로 두 목록을 구성한다. 유효한 응답에서 판단·근거가 빠진 항목은 해당 판단만 미확인으로 둔다. 자료 부족·판정 유보 항목도 공통 순위와 사람 채점에 남긴다. 카나리 조건은 상향 항목을 먼저 담는다. 각 순위 안에서 대안 평가가액과 공시 평가가액 차이의 절댓값을 공시 평가가액의 절댓값으로 나눈 변화율을 내림차순으로 쓴다. 동률은 기업 안에서 항목 ID 순이며 영향 미확인은 같은 순위의 뒤에 두고 항목 ID 순으로 정한다. 비교기업은 한 곳 제외를 기본 대안으로 쓰고, 적용 이익과 배수 집계는 결과를 확인하기 전 원문과 방법서에 근거한 대안을 항목별로 고정한다. 확인된 사실·계산 오류의 대안은 독립 검증한 입력·산식으로 재계산한다. 공시 평가가액이 0·미확인이거나 대안을 계산할 수 없으면 영향 미확인으로 두고, 계산을 마친 0%와 구분한다. 실행 중 가격 영향 중대성 문턱의 기본안은 5%다. 영향이 미확인이더라도 사전에 정한 필수 질적 조건을 충족하면 공통 검토로 보낼 수 있다. 사람 평가자는 별도의 정량·질적 기준으로 원본의 중대성을 판정한다.

기존 민감도 도구는 표시 배수로 평가가액을 재계산하고 비교기업을 제외할 때 산술평균을 사용한다. A1 정렬은 공시 평가가액과 공시에서 실제로 사용한 집계 방식으로 계산한다. 공시값과 재계산값이 다르거나 비산술 집계 방식을 쓰는 사례로 정렬 계산을 확인한다.

8.6 예산과 공정성

기존 B/A0의 발표값·버전별 상한은 개발 기록을 따른다. 최신 v0.4.3 개발 설정은 검토 실행당 모델 24회, 도구 40회, 누적 입력 800,000·출력 24,000 토큰, 900초, $1.25다. 기존 A0는 GPT-6.1 Terra를 사용했다. 독립 검토자 B는 다른 제공사 모델을 쓰는 안을 파일럿에서 검토한다. 각 역할의 모델, 공통 후보 자료 양식과 운영 모드의 상한은 평가 전에 고정한다. 기존 실행과 비용 기록

9.2 상태를 정하는 규칙

  • READY: 필수 형식을 채워 검토 초안을 제출했고, 실행 당시 중요한 미해결 정보 요청·사람 검토 요청을 표시하지 않은 상태.
  • PENDING_INFO: 중요한 판단에 필요한 정보가 아직 없고 요청이 남은 상태.
  • HUMAN_REVIEW: 해결되지 않은 해석·근거 충돌을 사람이 더 확인하도록 요청한 상태. 정보 요청도 함께 존재할 수 있다.
  • FAILED: 시간·자원 상한, 형식 불가, 실행 실패 등으로 유효한 최종 산출물을 제출하지 못한 상태.

최종 상태는 실행 제어기가 다음 구조적 규칙으로 계산한다.

유효 최종 제출 없음 → FAILED
미해결이며 blocking=true인 사람 검토 요청 있음 → HUMAN_REVIEW
미해결이며 blocking=true인 정보 요청 있음 → PENDING_INFO
그 외 → READY

각 요청·이관에 blocking, resolution_status, related_judgment_ids를 요구한다. blocking은 실행 당시 시스템이 해당 쟁점이 완료를 막는다고 표시한 값이다. 채점자가 사후에 중요성을 다르게 판단해도 final_status를 바꾸지 않고 잘못된 완료 또는 불필요한 보류로 채점한다. 이 실험에서는 실제 후속 응답을 주지 않으므로 정보·추가 사람 검토 요청은 원칙적으로 OPEN이다. 저장소에서 근거를 찾아 해소한 경우만 해결 근거와 함께 RESOLVED로 기록한다. 개별 항목 상태는 그대로 보존한다.

READY는 정답·안전·승인을 뜻하지 않는다. 사후 채점에서 잘못된 답을 READY에서 제외하지 않는다. 완성된 형식 안에 있는 틀린 판단이 바로 잔여 위험이다. 모든 상태의 제출물에 있는 오류를 별도로 집계한다.

조건부 수용이 실제로 중요한 미해결 가정에 의존하면 PENDING_INFO 또는 HUMAN_REVIEW로 표시해야 한다. 근거 없이 READY를 선택하면 잘못된 완료 처리로 채점한다.

A1은 유효한 A0 원본 제출이 없으면 FAILED로 기록한다. 유효 제출이 있으면 원본 근거와 1층 검사에 따라 공통 필수 목록의 미해결 중대 쟁점은 HUMAN_REVIEW, 필요한 근거가 없어 판단을 계속할 수 없는 경우는 PENDING_INFO, 그 외는 READY로 기록한다. B의 실행 실패는 별도 필드에 남기고 해당 후보의 판단을 미확인으로 둔다. 카나리 공동 미탐은 추가 검토 우선순위에만 반영한다.

11. 채점 지표와 분모

11.1 주평가지표와 보조 점수

두 핵심 조건에서 원본 검토 목록 안팎의 항목을 모두 사람 기준표로 채점한다. 주평가는 같은 공통 필수 검토와 추가량 K를 적용했을 때 기본 목록의 자연 중대 쟁점 누락 건수에서 카나리 목록의 누락 건수를 뺀 기업별 차이의 평균이다. 누락 비율은 분자·분모와 함께 보조로 보고한다.

목록 밖 중대 쟁점 비율 = 목록 밖 실제 중대 쟁점 수 / 전체 실제 중대 쟁점 수
목록 밖 실제 항목의 중대 쟁점률 = 목록 밖 실제 중대 쟁점 수 / 목록 밖의 판정 가능한 실제 항목 수

각 지표의 분자와 분모를 함께 보고한다. 판정 유보는 건수·사유를 제시하고 판정 가능 항목과 구분한다. 분모가 0이면 0% 대신 해당 없음으로 기록한다.

아래 방법론적 검토 충족률은 A0 보고서의 보조 평가와 기존 개발 검토에 사용한다.

사례 i, 반복 r, 조건 c에서 각 영역 J1–J4의 유효 기준표 항목 중 2점 항목 비율을 구한다. 네 영역 비율을 동일 가중 평균하여 V(i,r,c)를 만든다.

영역 방법론적 검토 충족률 = 2점 항목 수 / 해당 영역의 유효 필수 항목 수

FAILED에서 제출하지 못한 필수 항목은 0점이다. 단, 한 영역이라도 유효 gold 항목이 0이면 해당 기업의 충족률은 모든 조건·반복에서 NA로 처리한다. 나머지 영역만으로 재평균하지 않는다. 조건 비교는 모든 조건에 공통으로 유효한 기업만 사용하고 유효 기업 수와 제외 사유를 보고한다. 이 기업도 오류·실패·비용 등 산출 가능한 다른 지표에는 남긴다. 조건별로 유리한 기업만 분모에 남기지 않는다.

이 지표는 동일한 구성개념인 방법론 적용 품질을 요약한다. 비용·이관·오류를 가중 합산한 종합점수는 아니다. J1–J4별 결과도 반드시 함께 공개한다.

  • 공동 수용 원본 항목의 실제 쟁점률을 상향·기본·신호 미확인별로 집계한다. 기업·하위 유형의 적용 범위와 미확인 사유를 보고한다.

12.1 기업 단위 짝 비교

두 핵심 목록을 같은 기업과 같은 A0·B 원본 판단으로 짝짓는다. 주 효과는 기업별 기본 목록 밖 자연 중대 쟁점 수 − 카나리 목록 밖 자연 중대 쟁점 수의 평균이다. 두 목록과 기준표를 만들 수 있고 목록이 같은 기업의 차이는 0이다. 원본 판단이 일부 빠져도 확보한 공통 근거로 두 목록을 만들고, 빠진 판단은 미확인으로 기록한다. 두 목록이나 원본 기준표를 만들 수 없는 기업은 평가 불가 건수와 사유를 따로 보고하며 차이에 0을 대입하지 않는다. 기업별 누락 건수와 차이, 개선·악화·동률 기업 수, 전체 분자·분모, 교체 수와 새로 포함되거나 밀려난 중대 쟁점을 함께 보고한다. 불확실성을 추정할 때는 기업 단위의 짝을 유지한다.

사람 기준표의 판정 유보는 목록 안팎의 건수와 이유를 별도로 보고한다. 교체된 항목에서 미확정 중대성이 결과를 바꿀 수 있는 범위는 확정 쟁점의 차이에서 밀려난 판정 유보 수를 뺀 값부터, 그 차이에 새로 들어온 판정 유보 수를 더한 값까지로 보고한다. 두 목록에 공통인 항목의 유보는 차이에 영향을 주지 않는다. 같은 기업의 여러 카나리·항목은 잠근 B 응답과 유형 신호를 공유할 수 있다. 독립 단위는 발행기업이다.

A0 단독, 무작위 동일 개수, 명백한 오류만 사용한 방식, 동일 비용 A0 반복은 보조 비교로 사전 지정할 수 있다. 기업별 신호의 추가 가치를 진단하려면 같은 하위 유형 내에서 유효한 신호를 기업 사이에 섞되 상향 규모를 유지하는 보조 비교를 지정한다. 상태별 오류와 READY 비율도 함께 본다.

12.2 소표본과 심은 쟁점

개발에서 자연 중대 쟁점 수, 공통 필수 항목 밖 중대 쟁점 수, 추가 목록이 달라진 기업 수를 확인한다. 본 평가의 최소 의미 있는 누락 감소폭과 필요한 정밀도를 사전등록하고, 이 기준으로 평가 기업 수와 평가용 심은 쟁점 사용 여부를 확정한다. 사용한다면 최초 B 입력에 들어 있던 후보 중 신호용 카나리와 다른 후보로 평가용 원본 사본에 현실적인 문제를 하나 넣는다. 위치는 평가 담당자만 관리한다. 해당 사본의 A0만 한 번 추가 실행하고 잠근 B 답변을 연결해 같은 검토량에서 두 목록이 이를 포착했는지 평가한다.

자연 쟁점이 본 분석이다. 심은 쟁점은 별도 평가 지표로 보고하며 자연 쟁점에 대한 검정력이나 표본 수 계산에 합치지 않는다. 심은 쟁점의 포착과 추가 실행 비용을 별도로 제시한다. 자연 쟁점 분모가 0이거나 자료가 드물어 효과를 구분하기 어려우면 효과 추정의 불확실성과 판단 유보를 보고한다. 자동 통과는 실제 누락 감소, 기업 간 일관성, 탐지 상태별 근거와 정상 대조의 오경보를 확인한 뒤 별도로 검증한다.

12.3 결과표의 필수 열

자연 쟁점 결과표에 기업 ID, 평가 가능 여부와 불가 사유, 판정 가능·유보 항목 수, 실제 중대 쟁점 수, 공통 필수·추가 검토 수, 기본·카나리 목록 밖 중대 쟁점 수와 차이, 교체 수와 새로 들어온·밀려난 중대 쟁점 수, 유보를 고려한 차이 범위를 넣는다. 전체·평가 가능·평가 불가 기업 수와 평가 가능한 기업의 평균 차이를 제시한다. 별도 진단표에는 유형별 시험 수, 검토자별 탐지와 판단한 후보 수 및 전체 후보 수, 공동 미탐, 미확인·오경보, 원본 항목 연결, 사용량·비용을 넣는다. 평가용 심은 쟁점의 포착 여부와 추가 비용은 별도 표에 기록한다.

13.1 현실적인 비교기업 카나리 제작

  1. 최초 신고서의 업종·재무·사업 유사성 선정 기준을 원문 위치와 함께 옮긴다.
  2. 같은 업종 상장사 중 독립 후보 기준을 통과하고 목표 하위 유형에서 차이를 보이는 후보를 찾는다. 매출원·고객·판매 방식 가운데 확인할 차이를 사전에 정의하고, 차이를 뒷받침하는 원문 위치 두 곳 이상을 기록한다.
  3. 원본 기준일과 방식으로 배수를 계산하고, 교체 시 적용 배수와 주당 평가가액 변화를 확인한다.
  4. 사업 구조가 유사하고 배수 변화가 가능한 한 비슷한 정상 대조 후보를 찾는다. 각 사본에서 선정표·설명·배수·평가가액·할인율 적용 범위와 후속 참조표를 일관되게 맞춘다. 문서와 변경 위치, 확인한 수치의 출처를 기록해 개별 대조가 가능하도록 한다.
  5. 검토자에게 시험 후보가 드러나는 문항·파일명·검색 단서를 제거한다. 두 사본의 후보 자료 분량과 형식이 비슷한지 점검한다. 채점표에서 하위 유형·목표·증거·중대성·탐지와 오경보 기준을 고정한다.
  6. 두 사람이 원문만으로 판정 가능하고 중대한지 각자 확인한다. 둘 중 한 사람이 충족하지 않는다고 판단하면 수정 또는 무효로 기록한다.

14. 사람 참여와 실제 업무 적용 주장

14.1 핵심 연구의 사람 참여

규리가 원본 기준표 작성과 1차 채점을 맡고, 원준은 기업·유형별로 사전 선정한 원본 판단형 항목을 별도로 채점한다. 두 사람은 카나리·모델 답변·두 목록을 가린 상태에서 원본 기준표를 확정한 뒤 현실적 시험의 판정 가능성과 중대성을 함께 확인한다. 원본 기준표는 변형 제작 담당자에게 제공하지 않는다. 사람 검토 목록의 채점과 실제 업무 요청 해결을 각각 기록한다.

14.2 실제 후속 검토는 별도 모듈

후속 확인을 실제로 수행한다면 요청 시점 출력, 사람이 추가로 확인한 근거, 수정 결과, 소요 시간, 남은 문제를 따로 저장한다. 사람 개입 후 품질과 시간 절감에 대한 평가는 이 모듈에서 다룬다. 독립 교차 채점이 적용된 표본 범위도 보고한다.

14.3 실무 연결 산출물

  • 시험한 자료 구조에서 도구로 재현·검증할 수 있었던 작업.
  • 원문 근거와 한계를 붙여 보조할 수 있었던 해석.
  • 실행 중 관찰 가능한 추가 사람 검토·정보 요청 조건.
  • 문헌과 공개자료로 판단을 확정하지 못한 영역.

이 분류를 실제 결과로 채운다. 사람 요청의 필요성은 본 연구 기준표의 적합성으로 해석하고 독립적인 전문가 판단을 검증했다고 쓰지 않는다.

15. 선택 확장: 후속 공시·전향적 관찰

후속 정정은 최초 신고서 평가의 보조 자료다. 실제 정정된 항목 중 사람이 볼 목록이나 합의 지적에 들어갔는지 집계한다. 전향적 관찰을 추가할 경우 아래 절차를 별도로 적용한다.

  1. 후속 문서 공개 전에 사례·cutoff·입력·검토 메모·해시를 고정한다.
  2. 사전에 “어떤 판단이 어떤 새 자료로 확인되는가”를 적는다.
  3. 이후 정정, 최종 가격, 후속 재무자료를 별도 저장소에 수집한다.
  4. 검토 항목과 후속 증거를 연결하되, 회사가 수정하지 않은 질문을 자동 오답 처리하지 않는다.
  5. 추가 자료로 해소된 문제와 아직 알 수 없는 문제를 구분한다.

이미 정정 전후 내용이 함께 있는 최종 PDF를 과거 시점 입력으로 사용하지 않는다. 원래 시점의 파일을 확보하는 것이 우선이다. 구획을 제거해 시점을 복원한다면 원본·제거 범위·이유를 남기고 자연 원문 그대로의 실험과 구분한다.

  • [ ] 두 사람이 기업·유형별 사전 표본의 원본 판단형 항목을 카나리·모델 답변·검토 목록을 가린 상태에서 독립 채점했다. 조정 결과와 판정 유보를 기록하고 공동 카나리 확인 전에 원본 기준표를 확정했다.
  • [ ] 판정 유보 처리, 사전 유형 대응, 카드별 채점과 기준표 변경 기록을 준비했다.
  • [ ] 현실적인 카나리와 정상 대조의 시험 기준·두 사람 확인·미탐과 채점 불가 구분을 기록했다.
  • [ ] 양쪽 목록 안팎의 항목을 모두 채점할 수 있다.

실행

  • [ ] 보정의 기능 기준과 자연 쟁점 본 평가의 표본·정밀도 기준을 각각 확인했다. 모드·모델·계약·비용 상한을 확정했다.
  • [ ] 별도 세션과 섞인 순서로 진행하는 A0 실행, 발행기업당 독립 B 답변 한 건, 채점 짝 연결과 입출력 기록을 검증했다.
  • [ ] 두 목록은 같은 원본 A0·B·사실 및 계산 기록, 기업별 공통 필수 검토와 제한된 동일 추가량 K를 사용한다.
  • [ ] 실행 중 중대 문턱값, 유형별 가격 대안·동순위 규칙, 유효 쌍과 공동 미탐률 상향 기준을 고정했다.

분석

  • [ ] 발행기업·항목·변형·반복과 모델 호출을 별도 계수한다.
  • [ ] 자연 쟁점 누락의 기업별 짝 차이와 평균, 평가 불가, 교체 항목의 판정 유보 범위, 누락 비율의 분자·분모, 신호 미확인 기본 순위를 고정했다.
  • [ ] 실행 중 중대 판정과 사람 판정의 불일치, 미확인, 탐지·오경보와 비용을 병행 보고한다.
  • [ ] 평가용 심은 쟁점의 사용 여부를 정했다. 사용 시 신호용과 다른 후보, 결과표와 비용 기록을 마련했다.
