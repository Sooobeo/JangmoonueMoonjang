- [ ] 기존 계산기와 자료 확인 규칙을 활용해 단위·산식·주식 수·문맥·표시 정밀도를 검사한다. 정상 입력과 오류 입력, 원문 결측 입력으로 `통과 / 불일치 / 미확인`을 대조한다. 원문 대조와 재계산 결과를 각각 기록하고 규칙 버전·원문 위치·차이·사유를 남긴다.

## W11. 개발 기업 3곳에서 보정

- [ ] 가림 위반 없이 두 응답을 모두 채점할 수 있는 카나리 **6건 중 5건 이상**, 정상 대조 **3건 모두**를 확보한다. 공동 미탐과 한 명 이상 탐지가 각각 **1건 이상**, 목표 유형 오경보가 난 정상 대조본이 **최대 1건**인지 확인한다.
- [ ] 최소 한 기업·하위 유형에서 기본 응답 C1을 기준으로 서로 다른 유효 카나리 **2건 이상**과 공동 미탐률 **50% 이상**을 확인한다. 이 신호로 같은 `K`의 추가 검토 항목이 실제로 **1건 이상 교체**되는지 확인한다.
- [ ] 같은 A0 응답·원본 판단·필수 항목·`K`를 두고 시험 채점에 순서 변경 응답 C2를 대입한다. 탐지·오경보·상향·목록 교체를 C1과 비교한다. 한 기업이라도 추가 목록이 바뀌면 본 평가 전에 C의 운영 규칙을 다시 검증한다.
- [ ] **완료 기준.** 작동 기준의 충족 여부와 재보정 필요성을 기록한다. 목록 교체 빈도, 공통 필수 목록 밖 자연 중대 쟁점의 빈도, 제작·채점·실행 시간과 비용을 바탕으로 본 평가가 가능한지 판단한다. 관측이 부족하면 개발 사례를 보강하거나 효과 판단을 유보한다.

- [ ] **W12 · 사전등록.** 보정 결과에 맞춰 최종 평가 기업 수와 허용 자료, B의 규칙·출처·결과 처리 방식, C의 운영 규칙, 운영 모드, 예산과 작업시간 상한, 중대 기준, 기업별 `K`, 가격 영향·동률 정렬, 자료 부족·실패 처리, 기업 단위 분석법을 고정한다. 선택 사항인 확신도 비교와 평가용으로 심은 쟁점의 사용 여부도 정한다.
- [ ] **W13 · 본 실행과 독립 채점.** B로 자료별 사실·계산을 먼저 확인한다. 고정 입력으로 받은 A0 보고서와 C의 원본 판단, B의 검증 결과, 필수 항목, 추가 검토량을 두 조건에서 공유해 기본 목록과 카나리 목록을 만든다. 카나리 목록은 두 AI가 모두 수용했고 해당 기업·하위 유형이 상향 기준을 충족한 항목을 올린다. 신호가 없으면 기본 순위를 적용한다. 목록 확정 후 사람이 원본 기준표로 목록 안팎의 전체 항목을 대조하고, 평가 불가 기업은 사유를 남긴다.
- [ ] **W14 · 결과 보고.** 기업마다 `기본 목록 밖 자연 중대 쟁점 수 − 카나리 목록 밖 자연 중대 쟁점 수`를 구해 평균을 보고한다. 누락 건수와 분모, 개선·악화·동률 기업 수, 새로 들어온 쟁점과 밀려난 쟁점, 판정 유보의 영향, 오경보와 비용을 함께 기록한다. B 규칙 점검과 B 입력 효과, 평가용으로 심은 쟁점을 사용한 경우 그 성능을 별도 결과로 보고한다.
