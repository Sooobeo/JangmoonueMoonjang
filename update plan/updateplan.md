## 0. 한눈에 보기

- **연구 질문.** 두 AI가 최초 증권신고서의 공모가 산정에 동의했을 때, 그중에서 사람이 다시 봐야 할 판단을 더 잘 골라낼 수 있는가?
- **실험 조건.** A0는 원래 프로젝트의 개선 전 에이전트다. A1은 이 A0에 사실·계산 검사, 두 번째 검토자 B, 시험용 오류 검사(카나리)를 붙인 조건이다. A1은 A0 보고서에 검증 결과와 사람 확인 대상을 표시한다.
- **카나리의 역할.** 실제 신고서의 복사본에 연구팀이 미리 정의한 문제를 하나 넣는다. 비교기업 카나리는 업종은 비슷하지만 사업모델이 다른 기업처럼 실제로 놓치기 쉬운 사례를 사용한다. 원본 항목의 하위 유형과 기업별 카나리 배정은 사람 기준표를 작성하기 전에 확정한다.
- **순위 신호.** 같은 기업·오류 하위 유형에서 서로 다른 유효 카나리 시험이 2건 이상이고, 두 AI의 공동 미탐이 그중 절반 이상이면, 원본에서 두 AI가 모두 수용한 해당 하위 유형 항목을 상향한다. 유효 시험이 부족하면 미확인으로 표시하고 기본 순위를 쓴다.
- **핵심 비교.** 같은 원본 판단·공통 필수 목록과 기업별 추가 검토량 K를 쓴다. 사람 평가자는 목록 안팎의 원본 항목을 채점한다. 기업별로 두 목록 밖에 남은 자연 중대 쟁점 수의 차이를 구해 평균을 낸다.
- **단계별 검증.** 한 기업에서 4회 실행으로 작동을 확인한다. 세 개발 기업의 보정은 기본 15회와 B의 후보 순서를 바꾼 진단 3회로 총 18회다. 기업별 `B1`을 기본 채점에 재사용하고, `B2`로 실제 검토 목록이 달라지는지 확인한다.

## 1. 배경과 연구 범위

### 1.1 어느 시점의 무슨 판단을 검토하는가

최초 증권신고서에는 발행사의 사업·재무자료와 주관사의 희망 공모가 산정근거가 함께 들어 있다. 실적 기반 PER 방식이라면 발행사 자체의 적용 이익과 주식 수, 비교기업 선정 과정과 적용 배수, 주당 평가가액, 희망 공모가 범위가 서로 연결된다. 이 연구는 **최초 신고서가 공개된 때부터 기관 수요예측 전까지** 그 산정근거를 검토하는 상황을 가정한다.

| 검토 대상 | 예시 | 이번 설계의 처리 |
|---|---|---|
| 원문으로 확인할 수 있는 사실·계산 | 주식 수의 기준일, 억 원과 원의 변환, 평균 PER과 주당 평가가액의 산식 | 원문 대조와 재계산 |
| 근거를 따져야 하는 판단 | 어느 기업을 비교기업으로 볼지, 어느 실적 기간을 적용할지, 이례적 이익을 어떻게 다룰지 | 두 검토자의 판단 비교, 시험용 오류 검사, 사람 검토 |
| 공모 이후에 관찰되는 결과 | 수요예측을 거쳐 확정된 공모가, 후속 정정, 상장 후 주가 | 후속 정정만 보조 자료로 활용 |

최초 신고서 제출 이후 기관 수요예측을 거쳐 최종 공모가가 정해지고 청약이 진행된다. 금감원의 공시 심사와 기관 수요예측은 흐름에서 구분한다. 희망 공모가 산정근거를 투자자가 검토하는 시점이 연구의 초점이다. 주 사용자는 수요예측 전에 여러 기업의 신고서를 보는 **기관 애널리스트**다. 운용사·증권사의 리스크 및 AI 도입 담당자에게는 **어떤 항목을 왜 사람이 다시 봐야 하는지**를 근거와 함께 보여준다.

### 1.2 기존 에이전트에서 무엇을 바꾸는가

| 구성 | 맡는 일 |
|---|---|
| **A0** | 원래 프로젝트의 개선 전 에이전트. 실제 신고서와 산정표를 읽고 적용 이익(J1)·비교기업(J2)·민감도(J3)·추가 확인(J4)에 대한 검토 보고서를 작성한다. |
| **기존 프로토콜의 A1** | A0에 자동 검사와 제한된 재검토를 붙여 필요한 경우 에이전트가 보고서를 다시 제출하도록 한 개선안이다. |
| **A1 v4** | 같은 A0를 보고서 작성에 사용한다. 원문 대조와 재계산 결과를 별도 기록하고, 독립 검토자 B와 카나리로 실제 항목의 사람 검토 우선순위를 정한다. |

이번 실험은 동일한 A0 보고서를 각 비교 조건에 재사용한다. 계산 오류는 원문 위치, 독립 재계산 결과, 정정 제안을 별도 필드에 기록한다. 사람 검토 우선순위의 성능은 이 A0 원본과 추가 검증 기록을 기준으로 평가한다.

원래 프로토콜의 고정 절차 기준선에도 B라는 이름이 있다. 이 문서에서 **검토자 B**는 주관사의 선택을 가린 상태에서 산정근거를 독립적으로 재구성하는 두 번째 AI를 가리킨다.

## 2. 입력 자료와 접근 범위

| 자료 | A0에 제공 | 검토자 B에 제공 | 실험에서 하는 일 |
|---|---|---|---|
| 최초 증권신고서의 사업·실적·재무·주식 수 관련 자료 | 제공 | 근거 자료로 제공 | 신고서 최초 공개 시점을 입력 기준으로 고정 |
| 주관사의 최종 비교기업, 적용 이익, 배수 집계 방식, 산정표와 이를 드러내는 요약 문구 | 제공 | 가림 | B의 답을 받은 뒤 대조기가 읽음 |
| 비교기업 후보의 사업·재무·배수 자료 | 제공 | 최종 선정 여부와 선정 이유를 가린 후보 자료로 제공 | 후보별 판단의 이유를 확인 |
| 후속 정정 증권신고서·투자설명서 | 평가 입력에서 제외 | 평가 입력에서 제외 | 실제 정정 항목을 사후 보조 지표에 활용 |
| 시험용 변형본·정상 대조본 | 수정된 산정표와 해당 자료 제공 | 기업별 공통 가림 자료로 확정한 B 응답을 채점에 재사용 | 별도 채점기가 변형본별 목표 후보와 B의 응답을 대조 |

B의 과제는 후보군과 재무자료를 근거로 **적용 이익, 비교기업, 배수 집계 방식을 제안하고 이유를 설명하는 것**이다. 동일한 공모가 산정 항목을 대조할 수 있도록 정해진 양식으로 받는다.

### 2.1 최초 신고서와 공개 시점

기업별 최초 접수번호·문서 버전·해시·공개 시각(한국시간)과 시각의 확인 정밀도를 기록한다. 후보 기업 자료마다 출처·공개 시각·해시를 남긴다. 같은 날 공개됐어도 최초 신고서까지 이용 가능했다는 증거가 없으면 입력에서 제외한다. 최초 공시 시각을 날짜로만 확인한 경우에는 해당 신고서와 그 이전 날짜의 검증된 자료를 사용한다. 기존 개발 6곳과 평가 후보 12곳은 최종 문서 기준으로 준비한 명단이므로, 최초 신고서에 과거 실적 PER 산정과 필요한 원문이 있는지 다시 확인하고 사례를 확정한다.

### 2.2 후보군과 가림 자료

- 최초 공개 시점으로 정한 업종·사업·재무 기준을 상장사 자료에 적용해 후보 풀을 만든다. 주관사의 최종 선정표를 후보 선별 기준으로 사용하지 않는다. 원본 선택과 시험·대조로 채점할 후보가 공통 풀에 들어갈 수 있어야 한다. 선별 규칙의 예외나 필요한 근거가 없으면 해당 사례·시험의 적격성 또는 판정 가능 여부를 기록한다.
- B에는 한 기업의 공통 후보 풀과 근거를 제공해 한 번의 가림 검토에서 후보별 판단을 받는다. 모든 후보에 중립 ID, 공통 필드·형식·자료량 기준과 같은 순서 산정 규칙을 적용한다. 응답을 확정한 뒤 채점기가 원본의 선정 후보와 각 카나리·정상 대조본의 목표 후보에 해당하는 답을 찾는다. B 쪽의 시험 점수는 주관사 선택을 가린 상태에서 그 후보의 차이를 설명했는지 나타낸다.
- B의 검색·열람 도구에는 가림 자료만 허용한다. 문서 제목·URL과 메타데이터·검색 발췌·인접 쪽·교차 참조·캐시 결과에 실제 선정표나 시험 정답이 새지 않는지 실행 전 확인한다. A0의 자료에도 시험 표식을 노출하지 않는다. 파일럿에서는 정답표를 보지 않은 점검자가 형식이나 배치만 보고 시험 자료를 알아볼 수 있는지 확인한다.
- 가림 위반이 확인된 입력은 수정 후 다시 점검한다. 모델의 사전 기억이 의심되면 사유를 사전 규칙에 따라 표시하고 포함·제외 결과를 함께 보고한다. 가림 자체의 효과는 별도 보조 실험에서 B의 모델·근거·후보군·과제·채점 기준을 맞추고 최종 선택 표시의 공개 여부만 바꿔 비교한다.

### 3.1 1층 — 사실·계산 검사

공통 계산기와 근거 연결 검사기를 재사용한다. 이 검사기는 등록값의 산술·문맥 정합성, 실제 열람 여부와 근거 위치 필드를 검사한다. 허용된 페이지 안에서 잘못된 표의 값을 골라도 이 검사들은 통과할 수 있다. 원문 값과 주장까지 확인하려면 독립 추출 또는 사람이 원문에서 확인한 값과 표·행·열 위치를 대조한다. 구조 검사·재계산·원문 대조 결과를 별도 필드에 저장하고, 독립적으로 대조하지 못한 항목은 원문 미확인으로 둔다.

| 검사 | 확인 신호 | 보고서에 붙일 결과 |
|---|---|---|
| 단위·산식·주식 수 | 원문과 입력값이 다르거나 결과가 재계산과 불일치 | 출처, 재계산 결과, 수정 제안 |
| 시점·기간·연결 범위 | 기준일, 연간·누적 실적, 연결·별도 기준이 섞임 | 충돌하는 필드와 재확인 대상 |
| 반올림 | 차이가 원문의 표시 정밀도 범위 안인지 대조 | 표시 정밀도에 따른 차이 여부 |
| 근거 연결 | 주장에 인용이 없거나 인용한 위치에 근거가 없음 | 다시 찾아야 할 자료 또는 주장 보류 사유 |
| 정정본 혼입 | 최초 신고서 시점 이후의 자료가 입력에 섞임 | 혼입 위치와 재검토 대상 |

### 3.2 2층 — 원본 판단 비교와 시험용 오류 검사

**① 원본 항목과 하위 유형을 먼저 고정한다.** 사람 기준표를 작성하기 전에 기업별 항목 ID, 원문 위치, 실제 선택, 확인할 판단과 가격 대안을 기록한다. 같은 쟁점이 표·본문에 반복되면 같은 ID로 연결한다. 비교기업의 경우 원본에 채택된 후보별로 항목을 만들고, 모델 판단이 빠진 항목도 이 목록에 남긴다.

비교기업의 하위 유형은 **최초 신고서에 주관사가 명시한 그 후보의 선정 근거**를 개발 단계에 확정한 유형 사전에 대입해 정한다. 사전에는 `자체 브랜드 대 위탁생산 중심 매출`, `직판 대 도매 유통`처럼 유형별 선정 근거의 적용 조건과 우선순위를 적는다. 명시 근거가 여러 유형에 해당하면 우선순위가 가장 높은 한 유형에 연결한다. 근거가 불명확하거나 우선순위로 하나를 정할 수 없으면 미연결로 기록하고 기본 순위를 쓴다. 기업별로 항목 ID와 근거 인용·위치, 적용 규칙 버전, 연결 결과와 사유를 남긴다. 카나리 배정은 4.2절을 따른다.

**② 두 판단을 같은 항목에 연결한다.** A0는 기존 J1~J4 원본 보고서를 제출한다. 보고서 확정 뒤 동일한 추출·대조 절차로 명시적 판단과 인용을 항목 ID에 연결한다. 독립 검토자 B는 후보별 **포함·추가 검토·제외**와 출처, 적용 이익·집계 방식의 제안과 근거를 제출한다. 가림형 B 실행과 항목 판정 절차는 파일럿에서 별도로 준비한다. 기존 CLI의 고정 절차 B도 기존 이름으로 운용한다.

후보별 연결표에 중립 후보 ID, 원문 별칭, 응답의 해당 문장과 근거 위치, 최종 판정과 사유를 남긴다. A0가 비교기업 전체 구성이나 평균 배수만 수용하면 명시 판정이 없는 개별 후보는 미확인이다. 같은 후보에 상충하는 진술이 있으면 보고서가 명시적으로 정리한 최종 판단과 인용을 사용하고, 해소 여부가 불명확하면 미확인으로 둔다. 개발 사례에서 저장된 답변을 두 사람이 표본 대조해 후보 연결 오류를 교정한 뒤 규칙을 고정한다.

| 입력 응답 | 원본 대조기의 판정 |
|---|---|
| 해당 선택을 근거로 명시 수용. 중요한 우려를 해소한 조건부 수용 포함 | 수용 |
| 근거가 있는 추가 검토·제외, 또는 해당 선택을 반박하는 대안 및 이유 | 문제 제기 |
| 근거 없는 후보 누락·판단 누락, 또는 남은 조건을 해소할 자료 부족 | 미확인과 사유 기록 |
| 같은 원칙 아래 가능한 다른 제안을 했으나 원본 선택에 대한 명시적 판단이 없음 | 미확인. 제안과 근거 별도 보존 |

**③ 시험 자료와 응답의 연결을 사전 배정한다.** A0는 원본·시험·대조의 실행 순서를 섞고 자료마다 새 세션에서 시작한다. 기업별 가림형 B는 기본 응답(`B1`)을 한 번 제출한다. 두 검토자에게 이전 실행 내용이나 상대의 답을 전달하지 않는다. 채점기는 사전 배정표에 따라 변형본의 A0 응답과 `B1`의 해당 후보 판단을 연결한다. 탐지 결과를 보기 전에 각 실행의 입력·응답 ID를 고정한다. 개발 보정의 두 번째 B 응답(`B2`)은 11.2절의 진단에 사용한다.

요청 실패나 제출 계약상 전체 무효일 때 동일 입력·설정으로 1회까지 재시도한다. 유효한 제출의 후보 누락과 `PENDING_INFO`는 해당 내용대로 채점한다. A0 또는 B를 다시 실행해 응답 변동을 점검할 경우 진단으로 기록하고 최초 확정한 판단과 본 집계의 짝을 유지한다.

**④ 기업·오류 하위 유형별 공동 미탐률을 계산한다.** 두 응답 모두 채점 가능한 서로 다른 현실적 시험의 수를 `M`으로 두고, 양쪽이 같은 시험을 놓친 횟수를 `J`로 센다. `M ≥ 2`일 때 `J/M ≥ 1/2`면 상향 신호를 붙인다. 예를 들어 탐지자 수가 `(0명, 2명)`이면 `1/2`로 상향하고, `(1명, 1명)`이면 `0/2`로 기본 순위를 쓴다. 한쪽이 채점 불가인 시험은 그 짝을 분모에서 빼고 사유와 개별 결과를 남긴다. `M < 2`는 미확인이다. 두 시험이 실제로 같은 카나리의 반복이면 이 집계에서는 한 시험이다.

| 원본 결과 | 기업·하위 유형 신호 | 처리 |
|---|---|---|
| A0와 B의 판단이 갈림 | 전체 | 양쪽 근거와 가격 영향을 쟁점 목록에 기록. 중대한 불일치는 공통 필수 검토에 포함 |
| 둘 다 문제 제기 | 전체 | 합의된 지적을 기록. 중대한 지적은 공통 필수 검토에 포함 |
| 둘 다 수용 | 상향 신호 | 사전에 연결된 하위 유형의 원본 항목을 상향 |
| 둘 다 수용 | 기준 미충족 또는 미확인 | 각각 기록하고 기본 검토 우선순위 적용 |
| 한쪽의 근거 또는 필수 정보 부족 | 전체 | 자료 부족·판정 보류 상태와 필요한 자료를 기록 |

**⑤ 기업별 정렬과 검토량을 고정한다.** 공통 필수 항목을 두 목록에 모두 넣고, 남은 항목에서 기업당 `min(K, 남은 항목 수)`개를 더 고른다. 자료 부족·판정 보류 항목도 목록에 남아 순위와 채점 대상에 들어간다.

~~~text
1순위: 공통 필수 검토 (실행 중 중대 판정을 받은 불일치·합의 지적, 독립 대조로 확인한 중대한 사실·계산 오류)
2순위: 둘 다 수용 + 사전에 연결된 하위 유형의 상향 신호
3순위: 나머지 항목 → 가격 영향 큰 순
각 순위 안: 가격 영향 내림차순 → 같은 영향은 항목 ID 순 → 영향 미확인은 맨 뒤에 두고 항목 ID 순
~~~

카나리를 반영하지 않는 기준선(A0 + B)은 공통 필수 뒤 기본 순위로 채운다. 상향 신호가 없는 기업도 두 목록과 주 분석에 포함한다.

**⑥ 가격 영향과 두 가지 중대 판정을 정의한다.** 가격 영향은 공시의 주당 평가가액 `P₀` 대비 사전에 정한 대안 `P_alt`의 절대 변화율 `|P_alt − P₀| / |P₀|`이다. 값은 같은 단위·기간·배수 산정 조건으로 구하고 정렬에는 가능한 정밀도의 계산값을 사용한다. `P₀`가 0·미확인이거나 대안 계산에 필요한 입력이 없으면 가격 영향 미확인으로 기록한다.

| 원본 항목 | 가격 영향 대안 기본안 |
|---|---|
| 원본 비교기업 한 곳의 적합성 | 해당 기업만 제외하고 공시 집계 방식을 유지. 남은 비교기업으로 계산할 수 없으면 미확인 |
| 적용 이익·배수 집계 | 사전에 정한 하나의 실적 기간·조정 또는 집계 대안. 사례별 선택 이유와 적용 가능 여부 기록 |
| 확정된 사실·계산 오류 | 독립 확인한 올바른 입력·산식으로 같은 평가가액 재계산 |

기존 민감도 도구는 표시 배수로 재계산한 가격을 기준으로 삼고 비교기업 제외 시 산술평균을 쓴다. A1 정렬에 사용할 값은 공시된 `P₀`와 공시 집계 방식을 적용해 구한다. 공시값과 재계산값이 다르거나 비산술 집계 방식을 쓰는 예시로 파일럿에서 계산을 확인한다.

실행 중 기본 중대 기준은 절대 변화율 5% 이상이다. 가격이 미확인인 경우에도 출처·확인 필요성이 사전에 고정된 필수 질적 조건에 해당하면 공통 검토로 보낼 수 있다. 규리가 모델 결과를 보기 전에 가격 기준과 질적 조건을 정한다. 사람 평가자의 중대 판정은 원문 판단표로 별도 기록하며, 실행 중 판정과 어긋난 수와 이유를 보고한다.

### 3.3 최종 상태와 산출물

사람 검토로 보낸 항목에는 항목명, 원문 위치, 양쪽 판단, 평가가액 영향, 검토 우선순위의 이유를 붙인다. A0 보고서 원본과 추가 검증 기록은 같은 사례 ID로 연결한다.

~~~text
유효한 A0 원본 제출 없음 → FAILED
공통 필수 목록에 해소되지 않은 원본 중대 쟁점이 있음 → HUMAN_REVIEW
필수 근거가 없어 판단을 계속할 수 없음 → PENDING_INFO
현재 규칙에서 별도 조치가 지정되지 않음 → READY
~~~

카나리 공동 놓침은 추가 검토 우선순위에 반영한다. 원본 상태는 원본 근거와 1층 검사로 결정한다. 역할별 실행 실패와 추가 검토 목록은 별도 필드에 기록한다. READY는 실행 절차의 상태이며, 목록 밖 실제 오류는 7절에서 별도로 채점한다.

### 3.4 운영 모드와 비용

| 모드 | A0 검토 자료 | 기업당 검토 실행 수 |
|---|---|---|
| 작동 확인 | 원본 1건, 현실적인 카나리 1건, 정상 대조본 1건 | A0 3회 + B 1회 = 4회 |
| 절약 | 원본 1건, 같은 하위 유형의 서로 다른 현실적인 카나리 2건. 정상 대조 오경보율은 미측정으로 기록 | A0 3회 + B 1회 = 4회 |
| 기본 | 원본 1건, 같은 하위 유형의 서로 다른 현실적인 카나리 2건, 정상 대조본 1건 | A0 4회 + B 1회 = 5회 |
| 정밀 | 원본 1건, 현실적인 카나리 3건, 정상 대조본 1건. 여러 하위 유형에 배정한 경우에도 상향 최소 유효 짝 기준 적용 | A0 5회 + B 1회 = 6회 |

기본 모드의 자료 네 벌을 A0·B가 모두 별도 검토하면 기업당 8회다. B 응답을 공유하면 5회로 줄어든다. 각 검토 실행에는 여러 모델 호출이 들어갈 수 있으므로 실제 호출 수·토큰·시간과 비용을 기록한다. 기존 프로토콜의 공통 실행 상한을 넘는 구성은 조건별 실제 사용량을 함께 보고한다. 파일럿에서 기본 모드와 검토 대상 유형 수를 결정한 뒤 평가 전에 고정한다. 정밀 모드의 추가 비용이 크면 기존 문서의 **같은 비용의 A0 반복 실행**을 보조 기준선으로 둔다.

표의 실행 수는 기본 배정이다. 기술적 재시도와 진단 실행은 역할별로 추가 계상한다. 세 기업 보정은 기본 15회에 `B2` 3회를 더한다. 평가용 심은 쟁점은 같은 B 응답을 재사용해 기업당 A0 1회를 더 계상한다(절약 5회, 기본 6회, 정밀 7회). 확신도 보조 비교를 채택하면 기업당 모델 호출 2회를 추가로 기록한다. 제작 시간과 실행 비용도 함께 남긴다.

## 4. 카나리와 정상 대조본을 만드는 법

### 4.1 시험 자료의 세 종류

| 종류 | 무엇을 바꾸는가 | 무엇을 확인하는가 |
|---|---|---|
| 명백한 오류 | 무관한 업종의 기업을 비교기업에 포함하거나, 연결된 산식·단위에 원문으로 확인할 수 있는 오류를 추가 | 입력을 읽고 기본 문제가 드러나는지 확인 |
| 현실적인 오류 | 같은 업종 안에서 겉보기엔 그럴듯하지만 매출원, 고객, 판매 방식, 실적 정상화 등에 중대한 차이가 있는 선택을 삽입 | 실제 검토에서 놓칠 법한 중요한 차이와 그 근거를 지적하는지 확인 |
| 정상 대조 | 자료 형식과 변경량이 비슷하게 보이도록 후보를 바꾸되, 해당 시험 유형에서는 수용할 근거가 있는 선택을 삽입 | 바뀐 항목마다 경고하는 방식의 과잉 지적을 확인 |

명백한 오류는 기본 작동 확인에 사용한다. 원본의 판단 항목에 붙이는 우선순위 신호는 **해당 위험에 대응하는 현실적인 카나리**를 중심으로 평가한다. 정상 대조는 목표로 삼은 오류 유형에 한해 오경보를 채점한다. 별개 쟁점에 대해 근거 있는 지적을 하는 경우는 별도로 기록한다.

### 4.2 변형 규칙

**기업별 시험 유형과 배정을 사람 기준표 작성 전에 확정한다.** 개발 단계에서 하위 유형 순서, 시험·정상 대조 후보의 적격 조건과 동률 기준을 정해 같은 운영 모드의 모든 기업에 동일하게 적용한다. 3.2절에 따라 연결된 원본 항목이 있고 공통 후보 풀에서 해당 모드에 필요한 후보를 확보할 수 있는 첫 하위 유형을 고른다. 작동 확인은 현실적 카나리 1건과 정상 대조 1건, 세 기업 보정은 서로 다른 현실적 카나리 2건과 정상 대조 1건을 갖추어야 한다. 조건을 충족하는 유형이 없으면 미배정 사유를 기록하고 기본 순위를 쓴다. 후보를 고를 때에도 개발에서 고정한 적격 조건과 순서를 적용한다.

배정 기록에 기업 ID, 적용 규칙 버전, 원문 근거와 적격 여부, 배정 유형·시험 수 또는 미배정 사유를 남기고, 기록의 해시와 확정 시각을 저장한다. 기준표 작성 전에 배정을 정정하면 이전 값, 정정 사유와 시각을 기록하고, 같은 버전의 규칙을 해당 표본 전체에 적용한다. 기준표 작성이 시작된 뒤 발견한 부적격은 미배정 또는 변형 무효 사유로 기록한다. 규칙 수정은 개발 사례에서 검증한 뒤 다음 평가 표본에 적용한다. 사람 평가자는 기준표를 확정할 때까지 목표 후보와 변형 자료를 보지 않는다. 두 사람은 기준표 확정 뒤 정해 둔 규칙으로 변형을 제작·검증한다.

1. **개발 실패를 구체적인 하위 유형과 연결한다.** A0가 업종은 확인했지만 매출원을 놓쳤다면 ‘자체 브랜드 대 위탁생산 중심 매출’처럼 근거의 축을 좁힌다. 매출원과 유통 방식처럼 서로 다른 축을 합칠 때에는 적격 조건과 합치는 이유를 원본 채점 전에 정한다. 최초 파일럿은 비교기업 하위 유형 하나로 시작한다.
2. **시험 대상 선택 하나를 바꾼다.** 비교기업 한 곳을 바꾸면 A0용 자료에서 최종 목록, 선정 설명, 평균 배수, 평가가액, 해당 변경이 반영되는 표·본문·각주·주당 할인 적용 결과를 함께 맞춘다. 원본은 따로 보관하고 변경 위치·근거·가격 영향·다른 오류의 혼입 여부를 변형 기록에 남긴다. B에게는 2절의 같은 후보 자료를 제공한다.
3. **가격 영향과 목표 오류 유형을 함께 기록한다.** 정상 대조본도 가능하면 비슷한 양의 자료 수정과 유사한 배수 변화를 사용한다. 고PER 후보를 본 순간 경고하는 행동만으로 사업모델 차이를 맞혔다고 처리하지 않는다.
4. **시험 대상을 지목하는 표현을 막는다.** B에게는 같은 출력 양식으로 모든 판단 대상 후보의 근거를 받는다. A0와 B에 주는 파일명·요약·문항에서 시험 대상만 별도로 표시하지 않는다. 두 검토자에게 시험 대상의 판단에 필요한 사업·재무근거를 실제로 제공한다.
5. **채점 기준을 실행 전에 확정한다.** 시험본마다 목표 항목, 증거 위치, 중대한 이유, 탐지로 인정할 답변, 정상 대조의 허용 판단을 적는다. 사람이 자료로도 판단하기 어려운 변형이나 다른 오류가 섞인 변형은 시험 전 수정하거나 무효 처리한다. 정답을 보지 않은 다른 사람이 문서 형식·길이·배치로만 목표나 변형 여부를 알아낼 수 있는지도 확인한다.
6. **기업 단위로 기록한다.** 변형본은 같은 기업에서 만든 시험 자료다. 기업 수, 실제 판단 항목 수, 변형본 수, 반복 실행 수를 따로 집계한다.
7. **상향 신호를 만들 하위 유형에는 서로 다른 카나리를 2개 이상 둔다.** 비교기업 시험에는 서로 다른 목표 후보를 사용한다. 다른 산정 선택을 시험할 때도 각각 대응하는 별개의 판단이 있어야 한다. 단일 카나리 작동 확인에서는 동일 입력을 반복해 응답 변동을 기록할 수 있다. 반복은 서로 다른 유효 시험 수에 추가하지 않는다.
8. **실제 기업 자료로 만든다.** 같은 업종 상장사 중 사업보고서의 매출 구성으로 차이가 확인되는 실제 기업을 쓴다. PER 등 배수는 원본 신고서의 기준일과 같은 방식으로 맞춘다.

### 4.3 탐지와 오경보의 기준

- **사실·계산형.** 해당 항목을 특정하고 원문 값과 불일치를 근거로 지적하면 탐지다.
- **판단형.** 해당 후보나 산정 선택을 특정하고, 검토에 영향을 주는 구체적인 차이를 자료에 근거해 설명해야 한다. 그 차이를 이유로 추가 검토·제외를 요청하거나, 차이를 인정한 상태에서 포함 근거와 민감도를 제시하면 탐지로 기록한다.
- **유효 응답의 후보 누락.** 필요한 증거를 실제 제공했고 응답을 읽고 채점할 수 있는데 목표 후보·근거가 빠지면 시험의 미탐이다. 이유 없는 제외도 미탐이다. 원본의 해당 선택에 대한 판단 누락은 별도로 미확인으로 코딩한다.
- **정상 대조.** 근거가 충분한 후보에 대해 시험이 겨냥한 문제를 근거 없이 있다고 주장하면 오경보다.
- **채점 불가.** 필요한 증거가 실제로 누락되거나 요청이 실패했거나, 응답을 읽을 수 없거나 검증에 필요한 항목 연결을 복원할 수 없으면 채점 불가다. 제공 여부는 입력 기록으로 확인한다. 모델이 자료가 없다고 답한 경우에도 실제 입력에 충분한 자료가 있으면 그 답을 채점한다.

### 4.4 현실적인 비교기업 카나리 제작 순서

| 단계 | 할 일 | 자료 | 남길 기록 |
|---|---|---|---|
| 1 | 원본 신고서의 비교기업 선정 기준(업종 코드, 재무 기준, 사업 유사성 설명)을 표로 옮김 | 원본 신고서 | 기준별 원문 위치 |
| 2 | 같은 업종 코드 상장사 중 1차 기준은 통과하지만 매출원·고객·판매 방식이 뚜렷이 다른 후보를 찾음 | 후보 기업의 사업보고서 매출 구성, 주요 제품·고객 | 차이를 보여주는 원문 위치 2곳 이상 |
| 3 | 원본 기준일과 같은 방식으로 후보의 배수 계산, 바꿨을 때 평균 배수와 주당 평가가액 변화 계산 | 기준일 주가·이익 | 가격 영향 (중대 기준 이상인지) |
| 4 | 같은 절차로 정상 대조 후보를 찾음. 사업 구조가 비슷하고 배수 변화량이 가능하면 비슷한 기업 | 같은 자료 | 수용 근거 원문 위치 |
| 5 | 최종 목록·선정 설명·산정표와 파생값을 함께 갱신. B 가림 자료는 공통 후보 풀로 고정 | 원본 사본·독립 후보 목록 | 원본 대비 수정 내역, 재계산, 누출 점검 |
| 6 | 두 사람이 모델 실행 전에 독립적으로 판정 가능성과 중대성을 확인하고, 정상 대조본의 적격 근거도 확인. 하나라도 기준을 충족하지 않으면 수정 또는 무효 | 4.2의 채점 기준과 점검본 | 두 판정, 변경 이력, 무효 사유 |

카나리 한 개에 드는 시간은 파일럿에서 잰다. 이 값이 기업 수(멘토 P3)와 카나리 수 사이의 교환 관계를 정하므로, 11절 진행·중단 판단에 함께 쓴다.

## 5. 예시 — 가상 화장품 기업

발행사는 자체 브랜드로 화장품을 판매한다. 적용 순이익은 10억 원이고 적용 주식 수는 500만 주다. 세 비교기업의 PER이 12배, 15배, 18배라면 평균은 15배이고 주당 평가가액은 **3,000원**이다. 아래 기업·숫자는 모두 흐름을 설명하기 위한 예시다.

### 5.1 현실적인 카나리를 만드는 과정

1. **원본.** 비교기업 Y가 15배로 들어 있다. Y는 자체 브랜드를 보유하지만 주석을 보면 매출의 60%가 위탁생산에서 나온다. 주관사는 자체 브랜드 판매 사업의 유사성을 Y 선정의 주요 근거로 사용했다고 가정한다.
2. **서로 다른 두 변형본.** 한 사본에서는 Y 자리에 매출의 80%가 위탁생산인 Z를, 다른 사본에서는 70%가 위탁생산인 Z2를 넣는다. 둘의 PER은 예시에서 각각 30배다. 각 사본의 평균 PER은 20배, 주당 평가가액은 4,000원이다. Y, Z, Z2는 모두 ‘자체 브랜드 대 위탁생산 중심 매출’ 판단에 연결한다.
3. **기대하는 응답.** “Z의 위탁생산 중심 매출 구조는 발행사의 자체 브랜드 사업과 다르고, 마진이나 성장성을 같은 기준에서 비교하기 어렵다. Z 포함·제외 시 주당 평가가액을 확인할 필요가 있다.” 이 수준의 지적을 탐지로 인정한다.
4. **정상 대조본.** Y 대신 자체 브랜드 매출과 판매 구조가 발행사와 유사한 다른 후보를 넣는다. 그 기업의 PER도 30배로 맞출 수 있다. 이 경우 높은 배수에 관한 합리적인 질문과 사업모델 불일치에 대한 근거 없는 경고를 구분한다.

### 5.2 시험 결과를 실제 원본에 적용하는 과정

| 원본에서 검토한 항목 | A0 | 검토자 B | 검토 우선순위와 처리 예시 |
|---|---|---|---|
| 18배 비교기업 X 포함 | 수용 | 근거를 들어 제외 | X를 빼면 원본 평가가액이 3,000원에서 2,700원으로 바뀐다. 불일치와 가격 영향으로 쟁점 목록에 올림 |
| 15배 비교기업 Y 포함 | 수용 | 근거를 들어 포함 | 두 시험 중 한 건을 함께 놓치고 한 건은 누군가 탐지했다면 공동 미탐률은 1/2이다. 두 시험 모두 유효하므로 Y를 상향 |
| 적용 이익 기간 W | 수용 | 수용 | 대안 기간을 쓰면 적용 이익과 평가가액이 8% 낮아진다고 가정. 원래 이익 기간에 합리적 근거가 있어 사람 기준표에서는 수용 가능 |
| 발행사의 이익 정상화 | 문제 제기 | 문제 제기 | 두 AI가 함께 지적한 근거를 기록하고, 중요한 경우 사람에게 이관 |
| 적용 주식 수 | 수용 | 수용 | 원문과 산식은 규칙 검사로 확인하고, 해당 유형에 카나리가 없다면 시험 상태를 미확인으로 기록 |

원본 Y를 제외해도 나머지 12배와 18배의 평균이 15배여서 평가가액 변화는 0%다. 사람 기준표에서는 매출의 60%를 차지하는 위탁생산이 선정의 주요 전제인 자체 브랜드 중심 비교를 훼손하므로, 중요한 반대 근거를 설명에서 빠뜨렸다는 질적 기준으로 Y를 중대 쟁점으로 판정한다. X를 공통 필수로 두고 이 예의 추가 검토 자리를 한 개로 제한하면 기본 목록은 W를, 카나리 상향 목록은 Y를 추가한다. 예시는 규칙을 설명하기 위해 구성한 것으로, 실제 효과는 평가 기업에서 확인한다.

## 6. 연구 질문과 선행연구에서 가져온 요소

이번 설계는 규칙 검사, 독립 검토, 통제된 오류 주입을 결합한다. 기존 초안의 오류 주입·판정자 감사 연구는 검토자의 놓침을 측정하는 발상에, 판정자 간 오류 상관 연구는 합의를 해석하는 문제의식에, 감사의 분석적 절차는 독립적인 기대치를 만드는 접근에 해당한다.

이번 프로젝트의 검증 대상은 **IPO 검토에서 실제로 두 AI가 함께 수용한 판단 가운데, 시험용 오류 결과를 이용해 사람이 봐야 할 항목을 더 잘 골라낼 수 있는가**다. 다음 질문을 구분해서 답한다.

1. 두 검토자가 함께 놓친 시험 오류는 어떤 유형에 몰리는가?
2. 독립 검토자 B에게 주관사의 선택을 가리면 함께 놓치는 오류가 줄어드는가? 필요하면 같은 B의 모델·근거·후보군·과제와 채점 기준을 사용하는 별도 보조 실험에서 표시 공개 여부만 바꿔 비교한다.
3. 실제 검토 항목에서 **같은 사람 검토량**을 쓸 때 카나리를 추가하면 통과된 중대 쟁점이 줄어드는가?
4. 명백한 시험 문제와 현실적인 문제의 탐지 결과가 실제 신고서의 확인 필요 항목을 얼마나 잘 구분하는가?

**선행연구에서 가져온 요소.** FBI는 생성 답변에 통제된 변형을 넣어 AI 평가자가 품질 차이를 감지하는지 확인했다. Kim 외는 정답이 있는 다지선다와 사람 평정을 기준으로 삼은 주관적 이력서 평가에서 모델 오류의 상관을 분석했다. 이 연구에서는 그 문제의식을 IPO 검토에 적용한다. 같은 기업·오류 하위 유형의 공동 미탐 신호가 고정된 사람 검토량에서 실제 중대 쟁점을 더 많이 담는 쪽으로 우선순위를 바꾸는지 비교한다. [FBI 원문](https://arxiv.org/html/2406.13439v2) · [Kim 외 원문](https://arxiv.org/html/2506.07962v1#S2)

**이 연구의 차별점.** 기업별 시험에서 두 AI가 함께 놓친 하위 유형을 찾아 한정된 사람 검토 자리를 배정한다. 순위 계산 시에는 원본의 사람 기준표를 가리고, 목록을 확정한 뒤 기준표와 대조한다. 신호 섞기 대조는 기업별 시험 자체의 추가 가치를, 확신도 보조 비교는 구현이 간단한 자기 확신도 신호로 얻을 수 있는 결과를 같은 K에서 확인한다.

기존 문헌 목록은 12절에 유지한다. 비교할 선행연구의 주장과 범위는 발표에서 인용하기 전에 원문과 발표 상태를 확인한다.

## 7. 성능 검증

### 7.1 원본의 사람 기준표

**개발 사례와 평가 사례를 발행기업 단위로 나눈다.** 개발 사례에서 카나리 유형·탐지 기준을 만든다. 원본 항목 매핑과 기업별 배정은 3.2절과 4.2절에 따라 사람 기준표 작성 전에 고정한다. 우선순위 규칙과 중대 기준은 모델 결과를 보기 전에 고정한다. 평가용 사람 기준표는 모델 프롬프트, 검색 자료, 카나리 제작에 제공하지 않는다.

사람 평가자는 시험 자료·모델 판단과 두 조건의 목록을 가린 상태에서 공통 항목 ID의 원본 자료만 보고 허용 근거, 쟁점, 원문 위치를 기록한다. 목록 안팎을 포함한 전체 항목을 고정하고 나서 두 목록과 대조한다. 쟁점이 없는 항목과 경미한 오류가 확인된 항목을 별도로 기록한다.

| 사람 기준표 판정 | 구체적인 기준 |
|---|---|
| 수용 가능 | 원문의 사실과 어긋나지 않고, 선택을 뒷받침할 합리적인 근거가 있음 |
| 비중대 쟁점 | 오류나 미흡한 근거가 확인됐으나 사전에 정한 가격·질적 중대 기준에는 미달 |
| 중대 쟁점 | 중요한 반대 근거 누락이나 사실 오적용이 확인되고, 사전 기준 이상의 가격 영향이 있거나 핵심 비교·회계 판단의 결론을 바꿀 근거가 있음 |
| 판정 유보 | 공개자료만으로 적절성이나 중대성을 판정할 근거가 부족함 |

사실·계산 항목의 오류는 원문 대조와 독립 재계산으로 확인한다. 판단 항목에서는 가능한 비교기업이나 이익 기간을 하나로 고정하기보다 **여러 수용 가능한 판단과, 결론을 바꿀 수 있어 확인해야 하는 사항**을 기록한다. 중대 기준은 필수 판단 항목과 주당 평가가액 변화 폭을 함께 고려한다. 예를 들어 절대 변화율 5%는 검토할 후보값이다. 평가 전 팀이 결정한 실제 기준을 기록한다.

비교기업 적합성 등 판단형 항목에서 기업·유형별 표본을 미리 정해 두 사람이 독립 채점한다. 두 사람에게 카나리 자료·목표 후보, 모델 판단, 검토 목록을 가린다. 각자 원문 근거와 판정을 기록한 뒤 의견이 다른 항목은 근거를 대조해 조정한다. 합의가 안 되면 판정 유보로 둔다. 독립 판정, 일치 건수, 최종 판정과 사유를 남기고 같은 기업의 카나리 적격성을 함께 확인하기 전에 원본 기준표를 확정한다.

판정 유보는 목록 안팎의 건수와 사유를 남기고, 두 목록에 같은 판정을 적용한다. 유보 항목이 목록 교체에 걸린 경우 결과가 달라질 수 있는 범위를 7.5절에 따라 보고한다.

### 7.2 기준선과 공정한 비교 방법

| 조건 | 원본 항목을 검토 목록에 보내는 방식 | 해석 |
|---|---|---|
| **A0 단독** | A0 자체 지적·이관 결과 | 개선 전 에이전트가 놓치는 쟁점 파악 |
| **A0 + B** | 두 검토자의 판단과 공통 규칙 검사로 정한 필수 항목을 보낸 뒤, 기본 우선순위에 따라 추가 항목 선택 | 독립 검토와 공통 규칙 검사를 적용한 기준선 |
| **A0 + B + 현실적인 카나리** | 위와 같은 공통 필수 항목을 보낸 뒤, 두 AI가 모두 수용하고 3.2절의 상향 기준을 충족한 하위 유형의 우선순위를 높여 추가 항목 선택 | 카나리가 검토 순위를 개선하는지 확인 |
| **A0 + B + 자기 확신도** (선택) | 같은 필수 항목 뒤에, 두 AI가 모두 수용했고 두 확신도 중 낮은 값이 사전 기준 미만인 항목을 우선 검토 | 자기 확신도 신호로 얻은 목록과 카나리 목록을 비교 |

**핵심 비교는 두 번째와 세 번째 조건이다.** 같은 기업, 같은 원본 A0 보고서, 같은 검토자 B의 원본 판단, 같은 1층 검사와 공통 필수 목록을 사용한다. 기업마다 공통 필수 뒤에 같은 추가량 `min(K, 남은 항목 수)`을 배정한다. 시험이나 모델 출력이 불완전한 기업도 사전 선정 표본에 유지한다.

원본 A0나 B의 전체 제출이 무효이면 해당 역할의 원본 판정을 미확인으로 두고, 확보된 공통 근거로 두 목록을 같은 기본 순위로 구성한다. 유효한 보고서에서 일부 판단만 빠지면 해당 항목을 미확인으로 유지한다. 카나리나 B의 응답을 채점할 수 없는 짝은 `M`에서 제외하고 유효 시험 수가 부족하면 기본 순위를 쓴다. 원본 공통 항목·두 목록·사람 기준표를 재구성할 수 없는 기업은 사유와 함께 평가 불가로 표시한다.

예를 들어 기업별로 같은 예산을 적용한 두 목록을 합산했을 때 기본 조건의 목록 밖 중대 쟁점이 6건이고 카나리 조건이 3건이면, 이 표본에서 같은 수의 검토 항목으로 목록 밖 중대 쟁점을 3건 줄인 결과다. 실제 분석에서는 바뀐 자리 수, 새로 포함된 중대 쟁점과 밀려난 중대 쟁점을 함께 센다. 같은 수의 검토 항목으로 비교한 결과를 보고하고, 사람의 읽기 시간 또는 원문 분량은 별도로 기록할 수 있다.

**신호 섞기 대조.** 기업별 신호 자체의 추가 가치를 보려면 같은 하위 유형에서 `M ≥ 2`인 기업끼리 상향 여부를 사전 고정한 난수 규칙으로 섞는다. 유효 시험이 부족한 기업은 미확인 상태를 유지한다. 같은 필수 목록·K·정렬 방식에서 비교하고 신호에 변이가 없으면 비교 불가로 기록한다.

**자기 확신도 보조 비교.** 채택 시 A0 보고서와 `B1`의 원본 판단을 확정한다. 각 검토자에게 자기 판단과 기존의 허용 근거만 주고 별도 호출 한 번씩으로 그 판단이 근거로 뒷받침된다고 보는 정도를 0~100으로 받는다. A0는 원본 항목 ID, B는 가려진 후보·판단 ID를 쓰고 채점기가 대응을 연결한다. 두 점수가 유효한 공동 수용 항목에서 낮은 점수가 기준 미만이면 상향한다. 점수가 없거나 범위를 벗어난 항목은 기본 순위를 쓰고 미측정 사유를 남긴다. 0~100의 정수 기준 중 개발 사례의 기업별 상향 후보 수가 두 조건에서 가장 비슷해지는 값을 고른다. 기업별 상향 후보 수 차이의 절댓값 합을 최소화하고, 동률이면 더 낮은 기준을 쓴다. 이 값을 본 평가 전에 고정하고, 같은 필수 목록·K·순위 내 정렬과 기업별 누락 차이 지표로 비교한다. 추가 호출과 비용을 기록한다.

보조 비교로 명백한 오류만 사용한 방식이나 같은 모델 비용의 A0 반복 방식도 둘 수 있다. 원래 프로토콜의 완료율을 비교할 때는 READY 비율이 비슷한 조건을 함께 확인한다.

### 7.3 지표와 기록 단위

| 지표 | 계산·보고 방식 |
|---|---|
| **주 지표인 기업별 자연 중대 쟁점 누락 감소량** | 기업별 `기본 목록 밖 자연 중대 쟁점 수 − 카나리 목록 밖 자연 중대 쟁점 수`의 평균. 두 목록과 원본 사람 기준표가 있는 기업을 포함 |
| 목록 밖 자연 중대 쟁점 수·누락률 | 두 목록별 총 누락 건수와 `총 누락 건수 ÷ 사람이 확인한 전체 자연 중대 쟁점 수`. 분자·분모를 함께 보고 |
| 목록 밖 실제 항목의 중대 쟁점률 | 목록 밖에서 중대 쟁점으로 판정된 수 ÷ 목록 밖의 판정 가능한 실제 항목 수 |
| 상향 신호별 실제 쟁점률 | 두 AI가 수용한 실제 항목을 상향·기준 미충족·미확인으로 나눠 중대 쟁점률과 분모 집계 |
| 공동 놓침률과 신호 적용 범위 | 기업·하위 유형별 `J/M`, 시험별 0·1·2명과 채점 불가 사유, 2건 이상 유효한 기업·하위 유형 수, 신호 미확인 기업 수를 기록 |
| B 반복에 따른 순위 변동 | 동일 A0와 원본 판단·K에서 `B1`·`B2`의 후보별 탐지와 정상 대조 경고, `J/M`과 상향 상태, 실제 추가 검토 항목이 바뀐 기업 수를 기록. 실행이나 채점 비교가 불가능한 건수와 사유를 함께 보고 |
| 개별 미탐률과 공동 미탐 | 같은 유효 짝에서 개별 미탐률의 곱과 실제 공동 미탐률을 기술적으로 비교. 한 기업의 B 응답을 재사용하고 시험 난이도도 달라질 수 있으므로, 기업·하위 유형·난이도별로 가능한 집계 범위를 표시 |
| 정합성 및 오경보 | 유형 연결 비율과 정상 대조본의 목표 유형 오경보를 기록. 두 응답을 채점할 수 있는 정상 대조본 중 한쪽이라도 근거 없이 목표 오류를 지적한 건수와 개별 검토자 건수를 함께 보고. 정상 대조본 없는 운영 모드는 미측정 |
| 목록이 달라진 정도 | 기업별 바뀐 자리 수, 새로 포함된·밀려난 중대 쟁점 및 유보 항목 수, 두 목록이 같은 기업 수, 자료 부족 및 실패를 보고 |
| 검토 부담과 AI 비용 | 필수·추가 검토 항목 수, 모델 호출·토큰·실행 시간, 카나리 제작·채점 시간, 파일럿에서 측정한 사람의 항목당 원문 검토 시간 |
| READY의 핵심 오류율 | 기존 프로토콜의 상태별 오류 지표로 보고 |
| 후속 정정 적중 | 실제 정정된 항목 중 쟁점·사람 확인 목록에 들어간 비율을 보조로 보고 |

같은 기업의 여러 항목에는 같은 시험 결과가 적용될 수 있다. 결과표에서 항목 수와 독립 기업 수를 함께 보여주고, 불확실성도 기업 단위로 해석한다. 중대 쟁점이 관측되지 않은 평가 묶음에서는 분모가 0임을 표시한다.

실행 중 중대 판정(3.2절 ⑥)과 사람 기준표의 중대 쟁점이 어긋난 항목 수, 실행 중 가격 영향 미확인 건수, 같은 카나리를 반복했을 때 탐지 결과가 바뀐 비율도 보고한다. 동일 카나리의 반복 결과는 신호 집계와 별도다.

### 7.4 자동 통과를 검토할 조건

파일럿에서는 **공동 놓침에 따른 우선순위 조정**을 검증한다. 검토 목록 밖에 남은 쟁점은 목록의 선별 성능을 보여 준다. 실제 운영에서 자동 통과를 검토하려면 적용 범위와 허용할 중대 오류 위험을 별도로 정하고, 새 기업에서 검증할 계획이 필요하다. 검토 순서 결과를 보고 확인할 사항은 다음과 같다.

- 같은 검토량에서 카나리를 붙인 쪽이 **실제 중대 쟁점을 덜 흘려보냈는지** 확인했다.
- 특정 기업 한 곳에 결과가 몰리지 않고, 관련 유형에서 탐지 0·1·2명의 차이를 판단할 만큼 자료가 있다.
- 정상 대조본의 오경보와 실제 미탐을 확인해, 탐지 성공이 쉬운 단서나 모든 항목에 경고하는 행동에서 나온 경우를 구분했다.

이 근거가 부족하면 우선순위 조정 방식으로 결과를 제시한다. 자동 통과 규칙을 새로 제안할 경우 개발 자료로 조건을 정하고, 본 실험과 구분되는 새 기업 사례에서 확인한다.

### 7.5 평가 규모와 별도의 심은 쟁점 실험

**자연 쟁점의 빈도.** 독립 표본의 단위는 발행기업이다. 기존 검토 보고서 점수는 최초 신고서에 자연 중대 쟁점이 얼마나 있는지를 측정한 값과 다르다. 여러 개발 기업의 최초 신고서를 채점해 전체·필수 목록 밖 중대 쟁점 수, 두 조건에 공통으로 적용 가능한 시험의 범위, K 경계에서 목록이 바뀐 기업 수를 함께 잰다.

**본 평가 규모.** 개발에서 관측한 빈도와 비용을 바탕으로 의미 있는 최소 차이, 예상 정밀도, 필요한 평가 기업 수를 사전등록한다. 기업별 목록이 같거나 중대 쟁점이 드물어 차이를 판단할 정보가 적으면 기업별 건수·분모를 보여 주고 판단 유보로 결론을 남긴다.

**별도 실험.** 평가용 원본 사본에 같은 하위 유형의 현실적인 오류를 하나 더 넣고, 두 조건에 같은 평가용 원본을 사용한다. 오류를 넣은 후보는 신호용 카나리 후보와 달라야 한다. B의 공통 후보 풀에는 처음부터 포함하고 목표의 위치와 정답은 지정된 제작·채점 담당자만 관리한다. 모델과 두 목록을 만드는 절차에는 목표 정보를 넘기지 않는다. 평가용 사본의 A0 응답과 같은 기업의 확정된 B 응답을 연결한다. 7.2절과 같은 K에서 평가용 쟁점이 들어갔는지 두 목록을 비교한다.

| 구분 | 신호용 카나리 | 평가용 심은 쟁점 |
|---|---|---|
| 역할 | 두 AI가 이 유형을 함께 놓치는지 재는 시험 | 우선순위 규칙이 사람 검토량을 제대로 배정했는지 재는 정답 |
| 들어가는 곳 | 별도 변형본 | 평가용 원본 (실제 항목과 함께 섞임) |
| 만드는 후보 | 후보 풀에서 하나 | 다른 후보 하나 (같은 기업을 두 번 쓰지 않음) |
| 해석 한계 | 4절 | 같은 유형끼리 만든 것이라 자연 쟁점보다 결과가 좋게 나올 수 있음 |

평가용 심은 쟁점은 통제된 오류가 목록에 들어가는 비율을 보여 주는 별도 성능 지표다. 자연 쟁점 주 분석의 기업 수나 검정력은 기존 표본과 사건 수로 판단한다. 추가 실행은 기업당 A0 1회다.

**주 분석.** 기업별로 `Δ = 기본 목록 밖에서 확인된 자연 중대 쟁점 수 − 카나리 목록 밖에서 확인된 자연 중대 쟁점 수`를 구하고 기업에 같은 가중치를 줘 평균을 낸다. 두 목록이 같으면 `Δ = 0`이다. 사전 선정 기업 수, 주 지표를 계산한 기업 수, 평가 불가 기업 수와 사유를 함께 보고한다. 개선·악화·동률 기업 수와 전체 자연 중대 쟁점 분모도 기록한다. 불확실성 산출 방법은 사전등록하고 같은 기업의 두 목록·여러 항목·변형본·반복을 한 단위로 묶는다.

**판정 유보의 영향.** 주 분석은 중대로 확인된 쟁점을 센다. 바뀐 자리에서 밀려난 유보 항목을 모두 중대로 가정하면 기업별 차이의 하한은 `Δ − 밀려난 유보 항목 수`다. 새로 들어온 유보 항목을 모두 중대로 가정하면 상한은 `Δ + 새로 들어온 유보 항목 수`다. 두 값을 각각 기업별로 평균 내고, 범위가 0을 포함하는지 보고한다.

## 11. 팀 결정과 파일럿 순서

### 팀이 정할 것

- B용 모델·공통 후보 선별 규칙·자료 양식과 검색 허용 범위. 보정 시작 전 `B2` 후보 순서의 난수 규칙과 씨앗값을 고정한다. 다른 제공사 모델을 시험할 경우 정보 가림의 효과를 비교하는 실험과 분리한다.
- 하위 유형 사전과 우선순위, 원본 항목 매핑·시험 배정 규칙, 시험·정상 후보의 적격 근거와 탐지·오경보 기준.
- 실행 중 중대 기준, 가격 대안, 독립 사람 기준표, 기업별 K, 기업·유형별 2인 독립 채점 표본.
- 운영 모드와 비용·작업시간 상한, 자연 쟁점의 의미 있는 최소 차이와 필요한 정밀도, 기업 단위 불확실성 계산 방법, 확신도 보조 비교와 별도 평가용 심은 쟁점 사용 여부.

### 11.1 개발 기업 한 곳에서 작동 확인

| 순서 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 최초 신고서 적격성을 확인하고 공통 항목·가격 대안·원문 기반 하위 유형·기업별 카나리 배정을 고정 | 원문 위치, 매핑·배정 기록과 버전·확정 시각 확인 |
| 2 | 목표 후보와 변형 자료를 가리고 원본 사람 기준표를 작성·확정 | 네 가지 사람 판정, 사전 표본의 2인 독립 판정 기록 |

멘토 공유 묶음에는 원본 기준표, 채점한 작동 확인 1건, 카나리·정상 대조의 제작·채점 근거, 가림과 역할 분리안, 같은 검토량 비교표를 포함한다. A0 원본의 유효 제출과 후보 연결을 확인한 뒤 여러 기업의 보정을 시작한다. 시험이나 B 응답을 반복하면 응답 변동을 확인할 수 있다.

### 11.2 개발 기업 여러 곳에서 본 평가 조건 점검

개발 기업 3곳에 각각 원본 1건, 같은 하위 유형의 서로 다른 현실적 카나리 2건, 정상 대조 1건을 준비한다. 기업·유형별 원문 매핑과 배정은 사람 기준표 작성 전에 확정한다. 기업당 A0 4회와 가림형 `B1` 1회로 기본 15회를 배정하고, `B2` 진단 3회를 더해 **총 18회**를 계획한다. 기술적 재시도는 추가 계상한다. 모형·자료·규칙을 수정했다면 튜닝에 쓴 답변과 보정 실행을 구분한다. 아래 기준은 보정 결과를 보기 전에 고정한다.

**B 후보 순서 진단.** 세 기업 모두 새 세션에서 `B2`를 실행한다. 사전 고정한 난수 규칙으로 `B1`과 다른 후보 제시 순서를 만들고, 후보 ID·근거 자료·모델·설정·검색 허용 범위는 동일하게 유지한다. 순서와 재실행 변동이 함께 반영되는 점검이다. `B1`은 원본 판정과 기본 신호에 사용한다. 진단에서는 자료별 A0 응답, 원본 판단, 필수 목록과 K를 고정하고, 카나리와 정상 대조를 채점할 때 `B2`의 후보 판단을 대입한다.

두 B 응답을 모두 채점할 수 있는 목표 후보의 탐지 변화 건수와 분모, B 응답별 정상 대조 오경보, 기업·하위 유형별 `J/M`과 상향 상태, 추가 검토 항목이 바뀐 기업 수와 바뀐 자리를 기록한다. 진단 비교가 불가능한 사례는 사유를 남긴다. **한 기업이라도 추가 검토 목록의 항목이 바뀌면** 본 평가 전에 B 운영 규칙을 개발 사례에서 다시 검증한다. 기본안은 기업별 `B1` 한 번이다. 두 번 실행해 어느 한쪽의 탐지를 채택하는 방안을 검토할 경우, 원본 판정 통합 방식과 정상 대조 오경보·공동 미탐·목록 교체·비용에 미친 영향까지 검증한 뒤 채택 여부를 정한다.

| # | 확인할 것 | 진행 기본안 | 설계 변경·판단 유보 |
|---|---|---|---|
| 1 | 자료 적격·가림·유효성 | 두 사람이 제작 자료를 사전 확인. 누출 없이 카나리 6건 중 5건 이상, 정상 대조 3건 모두에서 두 답변 채점 가능 | 가림 위반은 수정 후 재점검. 유효수가 부족하면 사유 기록 후 자료·응답 양식을 고쳐 다시 보정 |
| 2 | 구별되는 탐지 결과 | 유효 짝에 공동 미탐과 한 명 이상 탐지 결과가 각각 한 건 이상 | 한쪽에 몰리면 난이도·입력 근거·유형을 검토하고 새 시험 제작. 근거가 부족하면 판단 유보 |
| 3 | 정상 대조 목표 유형 오경보 | 유효 정상 대조 3건 중 한쪽 이상 근거 없이 경고한 자료가 최대 1건 | 두 건 이상이면 지시문·채점 기준을 검토한 뒤 보정 |
| 4 | 실제 상향과 목록 교체 | 최소 한 기업·하위 유형에서 서로 다른 유효 짝 `M ≥ 2`와 `J/M ≥ 1/2`를 확인한다. 같은 기업에서 해당 상향으로 기본 목록의 추가 검토 항목이 한 건 이상 교체되고 두 목록의 추가 검토 수가 같은지 확인한다 | 기업·유형별 유효 짝 수, 상향 대상 후보 수와 K 경계의 위치를 확인해 원인을 찾고 재보정한다 |
| 5 | 자연 쟁점 효과를 평가할 수 있는지 | 상향이 실제 발동한 기업·유형 수, K에서 교체된 기업 수, 교체된 항목의 채점 가능 여부, 필수 목록 밖 자연 중대 쟁점의 분포와 제작·실행 시간을 보고한다. 사전에 정한 효과 크기·정밀도·비용으로 본 평가 규모를 판단한다 | 교체나 자연 쟁점이 희소하면 개발 사례를 보강하거나 자연 쟁점 효과 판단을 유보한다. 평가용으로 심은 쟁점은 별도 실험으로 사용 가능 |

1~4번은 `B1`을 사용해 작동을 확인하는 기준이다. 5번은 본 평가에 필요한 교체와 자연 쟁점의 관찰 가능성으로 판단한다. 개발 표본에서 어느 목록이 더 유리했는지는 보정 결과에 기록한다. 작동 기준, B 반복 점검과 평가 가능성을 확인하면 B 운영 규칙, 그 외 실행 모드와 K·중대 기준·평가 규모·분석 규칙을 본 평가 전에 고정한다. 기준에 미달하면 수정할 항목과 재보정 조건을 기록한다. 자료가 부족하면 판단을 유보하고, 예산이나 입력 적격성 문제로 실행을 확보하기 어려우면 보정 또는 평가를 중단한다.
